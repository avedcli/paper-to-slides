# Claim–Evidence Specification — 论证审查规范

本文档规定 paper-to-slides 阶段 2 的全部判据：结论怎么定级、主张—证据矩阵怎么填、
替代解释怎么列、结论边界怎么写、不同论文类型各查什么、以及最后的追溯链。

**这一阶段不产出页面，它产出判断。** 判断错了，后面排版再漂亮也只是把错的结论排得更好看。

> **档位**：本文档整体属 **A 档（不可妥协）**——结论不越级、不杜撰、可追溯，任何场景都不能让。
> 唯一的例外是"需人工复核"状态（§7）：判断依赖领域知识时写明留给谁，但**不许整表填复核**。

## 1. 四个结论等级

| 等级 | 定义 | 判据（满足才算） | 典型措辞 |
|---|---|---|---|
| **L1 Observation** | 实验直接测到的现象 | 有读出、有对照、可重复 | `X treatment increased Y` |
| **L2 Association** | 两个变量共同变化，方向未定 | 相关成立，但无干预或时间顺序证据 | `Y correlates with Z` / `Y is associated with Z` |
| **L3 Causality** | 某因素对表型有因果作用 | 有干预（loss/gain），且特异性已评估（救援、必要性或充分性至少一项） | `X is required for Y` |
| **L4 Mechanism** | 对中间环节给出可检验解释 | 有中介证据（上下游、顺序、必要性/充分性），且替代通路已排除 | `X drives Y through W` |

**四级不是评分表。** 不是每篇论文都必须爬到 L4，也不是级别越高越好——乱标 L4 比老实标 L2 危害大得多。

判级的三个口径：

1. **看实验，不看作者措辞。** 作者写 "demonstrates" 不代表它是 L3；只能看有没有干预与特异性证据。
2. **一条主张一个等级。** 合取句（"X 存在 **且** Y 标记它"）里两半可能等级不同，拆开标。
3. **拿不准就往低标，并写明缺什么。** 标低了只是保守，标高了就是替作者背书。

### 1.1 常见越级

| 现象 | 实际等级 | 为什么 |
|---|---|---|
| 敲低后表型减弱，无救援 | L2–L3（视对照而定） | 脱靶未排除，特异性未建立 |
| 过表达后表型增强 | L2 | 过表达常引入人为效应，不能单独支持因果 |
| 抑制剂处理后表型变化 | L2 | 除非有靶点特异性验证（耐药突变、双靶点敲低） |
| 相关性分析 + 时间序列 | L2 | 时间顺序是必要不充分条件 |
| 共定位 / 共免疫沉淀 | L1–L2 | 说明"能在一起"，不说明"功能上必需" |
| 结构 + 突变体功能验证 | L3 | 结构给出机制假说，功能验证才把它推到因果 |
| 作者模型图 | L4 假说，非数据 | 模型是解释框架，不是实验结果 |

## 2. Claim–Evidence 矩阵

每条主要主张一行，写入 `claims.md`。字段缺一不可（确实为空写 `none identified` / `undetermined`，
不要留白）：

| 字段 | 填法 | 反例 |
|---|---|---|
| **Author claim** | 贴近原文措辞，标出处 | 用自己的话概括到失真 |
| **Direct observation** | 测到什么：方向、效应量、`n`、统计 | "Y 显著升高"（缺效应量） |
| **Inference** | 作者从观察推出什么；哪一步是推断 | 把推断写成观察 |
| **Evidence level** | L1–L4 + 支撑图号 | 只写 "strong" |
| **Evidence strength** | 对照齐全度、独立重复、救援/必要性实验 | 用"n=3"代替强度评估 |
| **Alternative explanations** | ≥1 条未排除的竞争解释 | `none`（除非能说明为何不存在） |
| **Decisive experiment** | 最能区分竞争解释的一个实验 | 写"需要更多实验" |
| **Confidence boundary** | 能说到哪一步 + **不能声称什么** | 只写正面结论 |

### 2.1 示例

```
Claim            : IL-33 通过 ILC2 促进皮肤屏障修复
Observation      : Il33-/- 小鼠在第 7 天屏障恢复率 42% vs 78%（n=6/组, p<0.01）
Inference        : IL-33 对修复速率有作用（作者进一步归因于 ILC2 激活）
Level            : L3（Il33-/- 与 ILC2 缺失表型一致，但无 ILC2 特异性救援）
Strength         : 两组独立实验一致；ILC2 过继转移部分恢复；缺 ILC2 条件性敲除
Alternatives     : ① IL-33 直接作用于上皮 ② 肥大细胞介导 ③ 微生物组差异
Decisive         : ILC2 特异性 Il1rl1 敲除 + 过继转移救援
Boundary         : 可称 IL-33 对修复必需；不可称"通过 ILC2"为唯一通路
```

## 3. 替代解释

**每条核心结论至少写一条。** 写不出替代解释，通常不是因为它不存在，而是没想。

按这个清单扫一遍，取适用的：

- **脱靶 / 特异性**：遗传操作是否影响旁路基因？抑制剂是否有同源靶点？
- **表达水平**：过表达是否超出生理范围？敲低残留是否足够？
- **细胞来源**：表型是否来自另一群细胞、另一组织？
- **时间**：观察窗口是否只覆盖一个阶段？再生/代偿是否掩盖了真实效应？
- **环境**：饲养条件、微生物组、饮食、昼夜节律是否在组间不同？
- **测量**：抗体特异性、门控策略、归一化方式是否引入偏倚？
- **统计**：多重检验、伪重复（把技术重复当生物学重复）、事后选点？

每条替代解释要标：**已排除（哪张图）/ 未排除（缺什么实验）/ 无法排除（技术或伦理限制）**。

> 只有"未排除且可排除"的才进"如果重做"的拓展讨论；
> "无法排除"的进 Limitations 的置信边界，不要写成"未来可以做"，那是空话。

## 4. 结论边界（Confidence boundary）

写法：**"能说到 X；不能声称 Y；因为缺 Z。"** 三句缺一不可。

常见边界类型：

| 类型 | 例子 |
|---|---|
| 因果 vs 相关 | 能说"必需"，不能说"充分" |
| 细胞自主 vs 非自主 | 能说"该群细胞参与"，不能说"细胞自主完成" |
| 单一通路 vs 主导通路 | 能说"通过 W 起作用"，不能说"只通过 W" |
| 模型 vs 人体 | 能说"小鼠皮肤"，不能说"人类患者" |
| 时相 | 能说"炎症期"，不能说"全程" |

**这个边界直接约束三处文字**，不得越界：

1. 页面标题（标题是主张，必须与等级匹配）；
2. Discussion 的 Key Findings；
3. take-home message。

## 5. 按论文类型取检查项

类型在阶段 1.2 判定。**只取适用项**，不要把整表压给每篇论文。

### 机制型基础研究
因果链是否闭合；必要性与充分性是否分别验证；救援实验是否特异（同源恢复 vs 异源过表达）；
是否有平行通路的排除；体内 vs 体外的结论是否混用。

### 组学与筛选
样本量与功效；批次效应是否与生物学变量混杂；多重检验校正；筛选阈值是否预先设定；
关键命中是否有独立队列/独立方法验证；是否报告阴性结果。

### 结构生物学
分辨率与局部分辨率（关键区域是否够）；模型与密度吻合（FSC、局部打分）；
构象异质性是否被单一模型掩盖；构建体是否含影响功能的突变/截短；
**结构结论是否被功能实验验证**（没有功能验证的结构只是 L1–L2）。

### 计算方法 / AI
训练/测试是否泄漏（同源、同家族、同批次）；基线是否公平（同数据、同算力）；
消融是否覆盖核心模块；泛化是否跨数据集验证；超参选择是否用了测试集；
湿实验验证的范围与强度。

### 临床研究
设计与偏倚风险（随机化、盲法、失访）；纳排标准与推广性；主要终点是否预先注册；
混杂控制；效应量 + 置信区间（不能只报 P）；临床意义 vs 统计显著性；不良事件。

### 理论与数学
假设是否明示；模型边界（适用范围）；推导关键步骤是否可复核；是否给出可检验预测；
与实验/观测的对应关系。

### 资源 / 技术平台
覆盖度与完整性；质控指标；与现有资源的比较（同一基准）；实际应用案例；可及性与维护。

## 6. 追溯链

每条核心主张建立四段对应，写在 `claims.md` 的同一行或引用块里：

```
原文证据   ：Fig 3c, p.5 ¶2, Methods 2.4（Fig S4b 支撑统计）
分析记录   ：claims.md 第 3 行（L3，边界：缺 ILC2 特异性救援）
页面落点   ：Slide 11 标题 + 图注第 2 行
讲稿落点   ：script §Slide 11 第 2 段
```

**抽查规则**（阶段 5.1 执行）：核心结论四处必须对得上；对不上时以**原文**为准，
改页面或改讲稿，不要改原文记录来迁就文案。

三类必须标 `unverified` 的情况：

- 原文没报告、但常识上"应该有"的（如对照的设置细节）；
- 从图中读数但未在正文/图注给出的数值；
- 外部来源（引用文献、数据库）未能核实的内容。

`unverified` **不得**在页面或讲稿里被写成肯定句；要么删掉，要么在讲稿里明说"原文未报告"。

## 7. 审查输出：三种状态

阶段 5.1 的十项检查，每项给一个状态：

| 状态 | 含义 | 动作 |
|---|---|---|
| **通过** | 有证据支撑，措辞与等级匹配 | 继续 |
| **需人工复核** | 判断依赖领域知识或用户偏好（如"这个对照在你的领域够不够"） | 写清把哪一条留给用户、为什么 |
| **未通过** | 措辞越级、证据缺失、无法追溯 | 必须修，不得交付 |

**不允许**为了省事整表填"需人工复核"——那等于把判断责任整体推回给用户，本阶段就白做了。

## 8. 常见错误

| 错误 | 后果 | 纠正 |
|---|---|---|
| 只按图总结，不判断整篇论证 | 每张图都讲到了，结论却不成立 | 先做 §2 矩阵与 §4 论证地图，再分页 |
| 把作者的 "demonstrates" 当成 L3 证据 | 替作者背书，听众追问时无法回应 | 看干预与特异性证据，不看动词 |
| 只写正面结论，不写"不能声称什么" | 汇报强度超过数据 | 每条主张补 Confidence boundary |
| Alternative explanations 写 `none` | 审查流于形式 | 按 §3 清单逐类扫，至少一条 |
| 审了全部背景句 | 时间耗尽在次要内容上 | 只审核心结论，背景一句带过 |
| 审查结论不回写 Figure Inventory | 两份文件各说各话 | Hole 列补"影响程度"，与 claims 对齐 |
| 把"无法排除"写成"未来可以做" | Limitations 变套话 | 无法排除 → 写进置信边界，不写进 Future |
