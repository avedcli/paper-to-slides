# Typography Specification — 内容文字层级规范

本文档定义 paper-to-slides **内容页（content / discussion）正文文字**的字号层级。

> **档位**：4 档阶梯与 14pt 地板属 **A 档（不可妥协）**——不允许"缩一点就塞下了"。
> 冲突裁决见 `SKILL.md` 开头「规则优先级总表」。

## 0. 这张表解决什么问题

生成阶段最常见的毛病是"为了塞得下而逐条微调字号"。实测一份 9 页的测试 deck，
出现了 **11 种字号**：`8.5 / 9 / 9.5 / 10 / 10.5 / 11 / 11.5 / 13 / 14 / 15 / 30 pt`，
其中 8 种低于 14pt，并且出现**层级倒挂**——组标题 11.5pt 比它下面的正文 14pt 还小。

观感上这就是"随手拖出来的 PPT"，而不是人工排的学术 deck。

本规范用**只有 4 档的字号阶梯**消灭它：

- 内容文字的字号**只能取表内值**，任何其他数值（13pt / 15pt / 17pt…）都判违规；
- 每段文字属于哪一档，由下面第 2 节的**顺序判定流程**决定，不允许自由发挥；
- 最小级别 = **14pt**，内容页任何文字都不得小于它。

## 1. 字号阶梯（唯一合法取值）

| 级别 | 角色 | pt（写入 PPTX） | 字重 | 颜色 |
|------|------|----------------|------|------|
| **L1** | 页面主句：分节页标题、结论页唯一主张、take-home | **26** | Bold | 主色 |
| **L2** | 页内小节标题 / 要点组标题（统领下面若干条） | **22** | SemiBold | 主色 |
| **L3** | 正文要点：bullet 主句 | **20** | Regular | 正文色 |
| **L4** | 末档：依附性子项、限定补充、占位框说明；**图注、引用占位、来源注、搜索关键词** | **14** | Regular | 子项用正文色，图注/引用用次要灰 |

**单位是 pt，不是 px。** 四档全是整数，OOXML 的 `a:rPr/@sz` 以 1/100 pt 存整数，
直接写 `sz="2600"` / `sz="1400"` 即可，不存在小数换算误差。

> px 仅作参考（96 dpi 下的等效显示尺寸 = pt × 4/3）：26pt ≈ 34.7px、22pt ≈ 29.3px、
> 20pt ≈ 26.7px、14pt ≈ 18.7px。**设计基准以 pt 为准**，不要再按 px 反推档位。

相邻档位的比例是 **26∶22 = 1.18、22∶20 = 1.10、20∶14 = 1.43**。L2 与 L3 只差 2pt，
光靠字号分不开：同页既有小节标题又有正文要点时，**必须靠字重（SemiBold vs Regular）
和位置（统领关系、缩进、上方留白）把两级拉开**，否则读者只会看到"一样大的字"。
若某页的 L2 只是为了分段、没有真正的统领关系，就用 L3 加重，不要硬加一级 L2。

写入时直接用：

```python
from pptx.util import Pt

TIER_PT = {1: 26.0, 2: 22.0, 3: 20.0, 4: 14.0}
run.font.size = Pt(TIER_PT[level])      # level ∈ {1..4}
```

**L4 是唯一的末档**：以前图注用单独的 17px 档（L5），现已并入 L4。
子项与图注共用 14pt，靠**颜色**区分（子项正文色、图注次要灰 `#64748B`），
不再靠字号区分——少一档，层级更清楚，也不会再出现"图注比子项还小"的疑问。

## 2. 层级判定流程（顺序判定，命中即止）

对每一段内容文字，**自上而下依次提问，第一个回答"是"的级别就是它的级别**：

| 步 | 提问 | 命中则 |
|----|------|--------|
| 1 | 它是不是这一页的**标题**，或这一页被允许的**唯一一句主张**（分节页大标题、结论条、take-home）？ | **L1** |
| 2 | 它**下面还有从属于它的内容**吗？（组标题、"Evidence for X:"、小标题下面的几条要点） | **L2** |
| 3 | 它**独立成句**，删掉它这一页的论证链就断了吗？ | **L3** |
| 4 | 它必须**依附上一级**才读得通，或它在**解释图与出处**而不是论断本身吗？（子项、括注、条件限定、`n = 3`、`mean ± s.d.`；图注、`(Author et al., Year)`、数据来源、占位框搜索关键词） | **L4** |
| 5 | 以上都不命中 | **这段文字没有级别 = 它不该出现** → 回文案预算删掉，或并入上一级 |

判定要点：

- 判定依据是**语义角色**，不是文本框的大小或位置。框窄不是降级的理由（那要改布局，见第 3 节第 6 条）。
- 一页里 L2 必须比 L3 大、L3 必须比 L4 大——**层级与字号大小的顺序必须一致**，出现倒挂即判违规。
  唯一的例外是 L4 本身（它是最小档，天生比正文小）。
- 拿不准时**取更高的级别**（宁大勿小），因为**内容文字**放不下时的正确解法是删字或拆页，不是缩小。
  （注意区分：这里说的是**内容文字**——我们自己排的、最小 14pt 那一套。**图内文字**是另一回事，
  它是第 4 步的记录值，既不能反过来放宽内容文字的要求，也不能当成为什么要拆页的理由；
  分级原则见 `SKILL.md` 开头的「每一页的四步决策顺序」。）

## 3. 硬性约束（A 档）

1. **只用表内值**：内容文字字号只能取 `{26, 22, 20, 14} pt`。
   任何其他数值都是违规——包括 13pt、15pt、17pt 这类"看起来差不多"的值。
2. **最小级别 14pt**：内容页不得出现小于 14pt 的文字。这条是**下界**，不是"建议值"。
   图注、引用、来源注也一律 14pt，**不存在"更小的注解字号"**。
3. **同级同尺寸**：同一页内属于同一级别、同一角色的所有文字，字号**完全一致**。
   同页四条 bullet 不许出现 20pt 与 19pt 混杂。
4. **一页最多 3 级**：四档里最多用三个。典型组合是 `L1+L3`、`L1+L3+L4`、`L1+L2+L3`。
   层级越多越像 PPT 装饰，越不像学术汇报。
   **模板标题占位符的字号不计入这 3 级**——它是模板的决定（本母板 26pt 正好等于 L1），
   不占用生成器自己选的三档；否则"标题 + 组标题 + bullet + 图注"这种正常页面会被误判超限。
5. **强调用字重或颜色，不用字号**。同一层级的文字要让人注意某一条时，
   加粗或改用主色，**不要**把它调大一号——那是把字号当排版工具滥用。
   要把**一组内容圈成一个模块**时，用下面「模块块：填充底 + 反白文字」的几何手段，同样不动字号。
6. **不许为塞下版面而降级或缩小**。文字放不下时的处理顺序是：
   **删字（正文 bullets ≤ 30 词，页标题不计入）→ 拆页 → 换布局模式**。字号从头到尾不动。
   14pt 是地板，不是"压缩时可用的余量"。
7. **档位与视觉属性成对**：L1/L2 用主色（`accent1`）、L3 用正文色、
   L4 子项用正文色、L4 图注/引用用次要灰（`accent5` #64748B）。
   同一段文字只能选一种角色色，不要出现"图注的字号 + 主色"这种搭配。
8. **一框一号**：一个文字框内只允许出现**一个**字号。需要两个层级就**拆成两个框**，
   层级感来自"框分立 + 档位差"，不来自"同一个框里调两号"。
   典型违规是"bullet + 它的括注"塞进一个框（20pt 与 14pt 混排）：读者读不出层级，
   `verify_deck.py` 也会直接判 FAIL。
   **注释类文字的既定出路是页底 `cap-band`，不是在正文框里拆第二个字号**：
   新名词背景（`Lgr5: intestinal stem-cell marker`）、试剂原理、缩写展开都归 `cap-band`
   （SKILL.md 3.6）。正文框只留名词本身，注释不进正文——这样既守住一框一号，
   又让注释不占 30 词预算。名词作限定语使用（`Lgr5+ stem cells`）不是注释，不用拆。
   两处不算违规：① `Fig. 5a` 那种"编号加粗 + 图题常规"是**同字号**加粗；
   ② 模板标题占位符的字号是模板决定（本母板 26pt = L1），不受此条约束。

### 模块块：填充底 + 反白文字（唯一的几何强调手段）

把**同一个模块**的几条内容圈成一个视觉单元，或给一句话结论加锚点。这是本 skill 允许的
**唯一**几何强调方式；除此之外不加卡片、不加阴影、不加描边、不加色条。

> **档位**：形态与对比度属 **A 档**（白字压浅底 = 交付失败）；"什么时候才用"与每页个数属 **B 档**。

**形态（固定，不做变化）**

| 项 | 取值 |
|---|---|
| 形状 | 矩形或圆角矩形，**无描边**：`shape.line.fill.background()` |
| 填充 | 主色 `accent1` 或其深阶；一页里这是**唯一**成片的彩色面积 |
| 文字 | 纯白 `FFFFFF`；字号**仍取阶梯档位** `26 / 22 / 20 / 14`，字重可加粗 |
| 内边距 | 左右 ≥ **0.14 in**、上下 ≥ **0.08 in**；`word_wrap=True`、`auto_size=NONE` |
| 命名 | `Mod-<slug>`（如 `Mod-first-branch`），**不得**以 `Rectangle` 开头 |

**什么时候才用**（不是"想强调就套框"）——满足其一即可：

1. 一页确有 **≥2 个并列模块**需要被分开（两套并列的实验、两条并列的机制分支、两组对照）；
2. 一句话 **take-home / 结论条**需要与其余内容分开。

**不许**：给每条 bullet 都套框（全框等于无框，一页切成七八个色块最像模板）；
拿它装图（那是图区，见 `layout-spec.md`）；拿它替代标题层级；拿它包住本页唯一一条 bullet
（那是 L1 主句，不是模块）。**每页上限 3 个模块块**（含结论块）。

**对比度硬门槛**：白字要求底色够深——`1.05 / (L_fill + 0.05) ≥ 4.5`，即填充色相对亮度
**L ≤ 0.175**。主题色偏浅（明黄、浅青、浅粉、亮橙）时用**加深 30–40%** 的版本，
**不要**白字压浅底：投影后既看不清字，也丢了块与底色的边界。

```python
def _lin(c):                       # sRGB 8bit -> linear
    c /= 255
    return c / 12.92 if c <= 0.04045 else ((c + 0.055) / 1.055) ** 2.4

def luminance(rgb):                # 0..1 relative luminance
    r, g, b = (_lin(v) for v in rgb)
    return 0.2126 * r + 0.7152 * g + 0.0722 * b

def white_readable(rgb):           # 白字可行？
    return 1.05 / (luminance(rgb) + 0.05) >= 4.5

def darkened(rgb, k=0.35):         # 主题色太浅时的兜底
    return tuple(max(0, round(v * (1 - k))) for v in rgb)
```

**为什么必须无边框**：描边会让它在极简版式里立刻显出"这是自己画的框"；填充块看起来像版式本身。
同理**不要**加阴影、不要用半透明填充（半透明底 + 白字在投影仪上直接糊掉）。

⚠ **命名避开 `Rectangle` 前缀**：`verify_deck.py` 把 `name.startswith("Rectangle")`
的形状算进图占比，一个叫 `Rectangle 3` 的模块块会把该页图占比虚抬十几到几十个百分点，
让诊断数字失真。用 `Mod-…`。

⚠ **框里的字仍在正文 30 词预算内**：模块块承载的是正文，不是图注。套框不产生任何额外文字配额——
"分模块"只改变视觉分组，不改变"一页只讲一件事、只留该留的字"。

## 4. 与模板的关系

| 元素 | 是否受本表约束 |
|------|----------------|
| 内容页标题（模板 title 占位符） | **模板给定**：本母板为 26pt，**正好等于 L1**，生成器不要手改它的字号 |
| 封面 / 分节页 / 作者页 / 收尾页的模板固有文字 | **豁免**：沿用占位符自带字号（封面 40pt 标题、16pt 副行等） |
| 页码、页脚、logo 字样 | **豁免**：模板/HF 决定 |
| 生成器在上述页面上**新增**的文本框 | **受约束**：必须落在表内档位（且 ≥ L4） |
| 内容页由生成器写入的任何文字 | **受约束** |

一句话：**豁免的是模板已有的东西，不是"生成器可以自己造小字"的口子。**

## 5. 与"图内文字"的区别

子图里被缩放的文字（坐标轴刻度、图例）**不是内容文字，不受本表约束**。
它的显示尺寸 = `源图文字 px × 缩放比 × 96`，由"不重叠约束下的最大缩放"决定，
是**结果而非可调项**（见 `layout-spec.md` 三），只记录、不调整、不上报。
`plan_layout.py` 报告时以 **14pt（≈18.7px）** 作为舒适线，低于它只打印一行说明。

## 6. 已作废的旧约定

| 旧约定 | 现状 |
|--------|------|
| 引用占位用 8–10pt（早期版本） | **作废**。图注/引用一律 L4 = 14pt + 次要灰 |
| 五档阶梯，最小档 17px（L5） | **作废**。已合并为四档，末档 L4 = 14pt |
| 按 px 设计、`pt = px × 0.75` 换算 | **作废**。改为 pt 基准，四档全为整数 pt |

内容页任何文字都不得小于 14pt，这一条没有例外。

## 7. 验收

```bash
python scripts/verify_deck.py output/deck.pptx --profile template_profile.json \
       --pages 9 --exempt 1,2,6,8,9
```

`[type scale]` 段会逐页列出"用到的字号 → 对应级别"，并对下列情况判 FAIL（退出码 1）：

| 判据 | 含义 |
|------|------|
| `below minimum tier` | 出现了小于 14pt 的内容文字（**含 12.75pt / 13pt 这类旧值**） |
| `off-ladder size` | 出现了 ≥14pt 但不在阶梯里的字号（如 15pt、17pt、20pt） |
| `too many tiers` | 单页层级数 > 3 |
| `mixed sizes in one textbox` | 同一个非标题文字框内出现 ≥2 个显式字号（如 20pt bullet 与 14pt 括注同框）——违反第 3 节第 8 条，把注释移进 `cap-band` 或拆框 |
| `inverted hierarchy` | 短标签（≤4 词、非标题、不在 y ≥ 6.85 图注带）比本页"正文块"（词数最多的框，**已排除 `cap-*` 图题行**）更小，且自身不是末档 |

`--tiers` 可覆盖阶梯（如实验室另有设计规范，**单位已改为 pt**），
`--max-tiers-per-page` 可放宽页内层级数。

## 8. 常见错误

| 错误 | 后果 | 纠正 |
|------|------|------|
| 逐条微调字号直到塞下 | 一页十余种字号，像随手拖的 | 字号锁死阶梯，改为删字 / 拆页 |
| 组标题比正文小 | 层级倒挂，读者抓不到结构 | 按第 2 节流程重新定级，L2 > L3 |
| 用 8.5–13pt 写图注与引用 | 投影后完全看不清 | 统一 L4 = 14pt + 次要灰 |
| 用"调大一号"做强调 | 破坏阶梯一致性 | 强调用字重或颜色 |
| 给图注单独留一档小字 | 又回到"注解字号"的老路 | 图注就是 L4，与子项同档 |
| 一框里塞 bullet 与它的括注（20pt + 14pt） | 两档混排，层级读不出，`verify_deck` 判 `mixed sizes in one textbox` | 首选把它写成正文句子成分（`the stem-cell marker Lgr5`，仍一个字号）；确实要单独成行就进页底 `cap-band`；再不行才拆成两个框（第 3 节第 8 条） |
| 卡片里塞 L3+L4 两级小字 | 信息密度过高，像论文缩印 | 回文案预算删字，一页最多 3 级 |
