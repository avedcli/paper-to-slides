# Outline Specification — 大纲结构规范

本文档定义 paper-to-slides 大纲（`outline.md`）各节的固定结构、写法标准与常见错误。

> **档位**：§0.3 四步顺序的第 1–2 步（问题 → 证据清单）与回退规则属 **A 档（不可妥协）**；
> §0.1 文案预算、§0.4 图占比、§0.5 文字层数属 **B 档（默认建议）**；
> Introduction 页数、作者页、Method 页数、拓展讨论属 **C 档（按场景决定）**。
> 冲突裁决见 `SKILL.md` 开头「规则优先级总表」。
大纲以英文书写，每页条目固定格式为：

```
### Slide N — <页面标题>
- Type: cover / author（标题固定写 `Authors`）/ section-divider / content / discussion
- Figures: Fig 1a, 1b（本页放置的子图，精确到子图号）
- Layout: <布局模式 + 各子图位置与相对大小意图>（含子图的页面必填，
  模式目录与写法见 layout-spec.md，示例："1+2 (fig1a big left)"）
- Bullets: <2~4 条页面要点，结论句式；每条前缀标层级，如 `[L3] MSM recovers slow motions`>
- Modules: <本页要分成哪几个并列模块、哪一块是结论块（每页 ≤3）；不分模块写 NONE。
  见 typography-spec.md「模块块：填充底 + 反白文字」>
- Captions: <**每张上页子图一行**，写在对应的子图正下方，不是页面底部一行：
    Fig. 5a  IL-13 suffices to expand Tuft cells
    Fig. 5b  KLRG1+ ILC2s expand 5-fold after IMQ
  编号按原文写全（`Fig. 5a`，编号与观察句之间只用两个空格，不加冒号/破折号/`·`/`|`）；
  一句话 ≤12 词、观察句式（"这张子图直接展示了什么"），
  不写本页结论、不写推断、不复述图上已画清的流程>
- Bottleneck: <本页的补充行（B 类，默认没有）：读图钥匙 / 逻辑前提 / 易误读点三选一，
  建议前缀标明类别（如 `[前提] Deletion is ILC2-specific; DCs untouched`）；
  门槛是"不写这行，听众会读错图或把结论判高"——只是"少知道一点"不算，
  **复述正文 bullet、复述图上已画清的流程/分组/坐标、解释本领域常识一律不写**；
  查不到实质卡点就写 `—`（常规结果，不必给理由），判据见 SKILL.md 3.6>
- Background: <本页新名词注释行（A 类，首现即写、每页都可以有）：≤10 词/名词，
  同页多个合并成一行、`;` 分隔，如 `Lgr5: intestinal stem-cell marker`；
  可含关键试剂原理（≤12 词，判据同 Bottleneck 的 B 类门槛）；均不计入 30 词；
  缩写展开写 `缩写：全称（翻译）`；本页没有首现名词、且无补充行则写 —>
- Evidence: <本页主张的结论等级 L1–L4，与 claims.md 对应行号>
- Budget: <默认 30；仅核心证据页可写 40，见 SKILL.md 3.2>
- Notes: <排版/补充说明，可选>
```

`Captions` 与 `Bottleneck` 是**两个不同位置**，不重复：`Captions` **必写**，逐图（图正下方，
命名 `cap-<label>`），写"这张图是什么"；`Bottleneck` **按需**，逐页（页面底部图注带，
`y ≥ scaffold_y`），写"目标听众读这页图最大的卡点"（读图钥匙 / 逻辑前提 / 易误读点，
SKILL.md 3.6 三问）。两者都属 L4 图注，都不计入正文 30 词预算。

`Background` / `Bottleneck` 两行**写在同一个 `cap-band` 里**（SKILL.md 3.6），但**权重不同**：
`Background` 是**名词注释行（A 类）**，判据只有一条——"这个词在本页之前建立过没有"，
没建立过就写，**每页都可以有，不设频率上限**；`Bottleneck` 是**补充行（B 类）**，
门槛是"不写会让听众读错图或判高结论"，多数页写 `—`。顺序固定为
**Background → Bottleneck → 试剂原理**（越靠前越是"读不读得懂"的前置条件）。
两行都是 `—` 的页**不建 `cap-band`**，`caption_band_in` 写 0；只写一行就是 0.42。
这两行都不计入正文 30 词预算，**也不写进正文 bullet 的括注**（正文框一框一号，混字号违规）。

页面标题必须用**科学问题或结论句式**（如 "Does X drive Y?" / "X is required for Y"），
禁止使用 "Results 1" / "Figure 2" 这类无信息标题。

**例外：非内容页用固定标签**。封面（写论文题目）、分节页（`Introduction` / `Methods` / `Results` /
`Discussion`）、**作者页（固定为 `Authors`，不写姓名、论文题目或疑问句，不加副标题）**、
收尾页的 take-home 句，都走模板固有权重与该页既有的标签语汇，不受上面的句式约束，
也不参与"标题 ≤12 词"的计数。**其中只有作者页是硬性固定措辞**（`Authors`），其余按各节既有规则写。
作者页的标题**不随汇报语言改**：中文汇报同样写 `Authors`。

大纲除页面条目外，**开头必须有一节「讲述方式与 take-home」**（阶段 3.0 的产物）：

```
## 讲述方式
- Mode: sequential（正常顺序讲述）/ backward（倒推讲述）/ hybrid
- Duration: <0.1 拿到的总时长 + 是否含提问；目标落在 90–100%>
- Audience: <0.1 拿到的听众背景：是否已读原文 / 同领域与否>
- Take-home: <一句话，≤25 词；措辞强度不超过 Confidence boundary>
- Killer data: Fig 3a（撑住前半分句）, Fig 5c（撑住后半分句）
```

另需一节「**修订记录**」：所有回退按 `SKILL.md` 开头的三类理由记录
（从哪一步回到哪一步、原因、影响哪几页）。没有回退就写 `none`。

另需一节「**未上榜内容备查**」，列出按 `figure-and-author.md`「哪些上 PPT、哪些只留大纲」
判定为不上页的读图笔记（实验设计的次要细节、次要对照、统计流水账等），供用户核对——
**这部分不计入页面词预算，但必须有**，否则用户无从判断取舍是否合理。
注意：**瓶颈行与关键试剂原理不在这一节**，它们属于页面的 `Bottleneck` / `Background` 字段
（这两个字段写 `—` 是合法值，代表"判过、不需要"）。

## 0. 写大纲的六件准备（按顺序，不可颠倒）

本节是写任何页面条目之前必须走完的准备段。产物依次是：
**文案压缩口径 → 讲述方式 → 问题 → 证据清单 → 坐标 → 层级标注**。

**前置条件**：阶段 2 的 `claims.md` 已完成。没有主张—证据矩阵就开始写页面，
分页会退化成"按图排页"。本章 §0.3 的四步只决定"每页怎么搭"，不决定"哪些话能说"。

四步默认不回跳；**允许三类科学理由的回退**（问题定义错、证据链断、替代解释未处理），
每次回退必须记进「修订记录」。完整论述见 `SKILL.md` 开头「每一页的四步决策顺序」。

### 0.1 文案预算（写大纲时就地压缩）

**每页正文区单词量 ≤ 30**。大纲是文案初稿，不是"待压缩的素材"——
在写大纲这一步就要压到位，不要留到生成阶段。

这个上限是 **B 档排版建议，不是科学约束**：一页要靠更多字才能讲清"做了什么、看到什么、
为什么这个证据站得住"时，**宁可变长，也不要为了压字删掉实验设计、关键对照或定量事实**（A 档）。
真空不下时的次序是**删修饰 → 拆页**，不是继续删科学内容。

- 只写**描述性短语**与**结论性短句**：
  - 好：`"MSM recovers slow collective motions"`
  - 差：`"In this work, we demonstrate that the Markov state model framework is able to
    successfully recover the slow collective motions that are critical for function"`
- 删掉：连接性铺陈（However / In addition / It should be noted that）、方法复述、
  与图上内容重复的描述。图上画出来的，不再写一遍。
- Bullets 每条 ≤ 10 词，每页 2~4 条；**页面正文区的 bullets 总词数 ≤ 30**。
  **页标题不计入这 30 词**（标题单独受 ≤12 词约束）——`verify_deck.py` 把 title 占位符
  单独统计，报 `body=` / `title=` 两个数，门禁只看 `body`。
  两条约束同时生效，条数多则每条更短（4 条时平均只剩 4–5 词，通常该拆页或减条）。
- **图题（逐图）**：一句观察，"这张子图直接测到什么"，≤ 12 词、最多 2 行。标题 ≤ 12 词。
- **30 词的分配顺序**（冲突时按此取舍）：① 实验设计 → ② 本页结论 → ③ 必要对照 →
  ④ 修饰与重复（先删这一档）。**新名词背景与试剂原理不在这 30 词里**，它们在图注带（见下）。
- **图注分两处，都不计入正文 30 词预算**：
  ① **逐图图题**（图正下方，编号 + 一句观察，≤12 词，一页合计 ≤40 词）——**这是必写的**；
  ② **页面底部图注带**（`scaffold_y` 以下，字数豁免）——两类行，判据不同：
  **名词注释行（A 类）首现即写、每页都可以有，不设频率上限**；
  **补充行（B 类：瓶颈 / 试剂原理）默认没有**，只在"不写会让听众读错图或判高结论"时才写，
  复述正文、复述图、解释常识的一律删。最多 3 行（SKILL.md 3.6）；
  每个 14pt 行占 0.237 in，规划时按行数把 `caption_band_in` 定到
  **0 行 0.00 / 1 行 0.42 / 2 行 0.66 / 3 行 0.90**；例行的 1 行就是 0.42。
  整份 deck 里**带补充行的页应少于 1/3**（名词注释行不计入这个比例）。
  更细的读图笔记（货号、配方、统计流水账）按 `figure-and-author.md`
  「哪些上 PPT、哪些只留大纲」留在本文档的「未上榜内容备查」节。
- **分隔短语只用空格**。文案里**禁止**出现 `·` 这类装饰性分隔符号
  （人类做 PPT 时几乎不用，一出现就像机器生成）：
  `期刊名 · 年份 · DOI` ✗ → `期刊名 年份 DOI` ✓；`corresponding author · 单位` ✗ → `corresponding author 单位` ✓。
  同理不用 `|` `•` `∙` 之类当分隔符；并列关系靠换行或空格表达。
- **豁免**（可超过 30 词，但仍需精简）：cover、author、section-divider、discussion、收尾页。

### 0.2 先定讲述方式（阶段 3.0，写任何页之前）

大纲的骨架形态取决于**讲述方式**，所以这是比下面四步更早的一问：

- **`sequential` 正常顺序讲述**——按论文逻辑正向展开（Intro → Method → Results → Discussion），
  页面顺序即论文 Figure 顺序。适合教学型、听众未读原文。
- **`backward` 倒推讲述**——先亮 take-home 与最强证据，再回填"为什么它能成立"。
  适合期刊俱乐部、时间紧、听众已读原文。
- **`hybrid` 混用**——主体顺序讲，在 Results 开头加一页结论预览，或在 Discussion 倒推收束。

选定后写进大纲开头的「讲述方式」节。**若选 `backward`（或 `hybrid` 的倒推段），
必须同时写死 take-home 与 killer data**，且 take-home 在收尾页/Key Findings 首条**原样出现**、
killer data 所在页优先拿最大图面积。若选 `sequential`，take-home 可留空。

⚠ 这一问**在写大纲前问用户**，不要默认替他选（用户没回应就不动笔）。

**时长与听众来自阶段 0.1**，本节只把它们抄进大纲头部，不再重复提问。
按时长反推页数（内容页 ≈ `时长 × 0.8~1.2`，另加封面/分节/按需的作者页约 +10%），再按节分配：
Introduction 15–20%、Method 5–10%、Results 50–60%、Discussion 15–20%。
目标落在时限的 **90–100%**；富余时按 §6 第 5 条做拓展，不足时先砍页不砍理解性信息。

### 0.3 写大纲的四步顺序（第一顺位，不可颠倒）

**大纲的全部价值就在这四步。** 每一步的产物依次是：**问题 → 证据清单 → 坐标 → 记录值**。
前一步没结论，不许进入下一步。**默认不回跳**——为了让图更大、字更大而回去改问题或证据归属，
是用排版反推科学，正是"看图说话"式 deck 的成因。

**允许的回退只有三类**：① 问题定义错了；② 证据链断了；③ 有未处理的竞争性解释。
每次回退记进「修订记录」。完整论述见 `SKILL.md` 开头「每一页的四步决策顺序」。

**第 1 步：这一页的科学问题是什么？** → 写进页面标题（结论/问句句式，≤12 词）
- 必须能用**一句**完整问句写出来。若答案里出现"和／以及／并且／同时"连着两个并列结论，
  说明这其实是两页。

**第 2 步：证明它需要哪些子图？** → 写进 `Figures` 字段
- 对每张候选子图问一句：**"它在为这个结论提供证据吗？"** 只收两类：
  - **必要证据**：拿掉它，本页结论就少了支撑；
  - **配套证据**：主证据的对照 / 统计 / 原始数据（多为 `Fig S#x`）。
- 再反向查**充分性**：这个结论的证据链齐了吗？
- 两条禁令：**"相关但非必需"的图不许放**（凑数）；**同一问题必需的图一张也不许挪到别页**（断链）。
- ⚠ **图数是这一步的结果，不是配额，也不是准入门槛。** 2–4 张只是诊断指标：
  少于 2 张时先问"它和相邻页是不是同一个问题"——是则合并，不是就让它独立成页；
  多于 4 张时先问"里面有没有可以独立成问的子问题"——有则拆页，没有就保留多图证据页。
  单图页合法（前提：独立问题 + 证据足够决定性），多图证据页也合法。**不要为了凑张数硬拆或硬并。**

**第 3 步：把图做到尽可能大且易读** → 写进 `Layout` 字段
- **这一层的优先级低于第 1–2 步**：本页叙述充实、证据链完整、关键证据可读，
  都比图占比这个数字重要。图占比只在这几件事成立之后尽量做大。
- 目标函数是**"大"**（选 `1x3` / `1+2` / `2x2` 中面板总面积最大的那个），
  **50% 是参考线与诊断指标，不是验收下限，也不阻塞交付**。
- 取到最大仍 < 50%：**只查一次"这一页有没有相关但非必需的图"**——
  有则移走重排（这本来就是第 2 步的禁令，不算为排版改科学）；
  没有就**接受**，在大纲/交付说明注明该页数值与原因。
  **不得**删必需证据、缩图、缩字、为凑数塞不相干的图。
- `Layout` 字段只是**意图声明**，实际坐标以 `plan_layout.py`（传 `min_text_px: 0`）的输出为准。

**第 4 步：读图体验** —— **大纲里不出现**
- 图内文字大小不进大纲、不进 `Layout` 字段、不参与任何取舍；它只在阶段 5 被实测并汇报。

### 0.4 图占比（第 3 步的**诊断指标**，不是约束）

除豁免页外，**每页都应把图取到布局允许的最大值**——这是唯一要求。
可用图区 = 内容区扣除标题带、图注带与页边距后的净面积，**不是整页面积**
（即 `layout.json` 里 `figure_coverage` 的分母）。

**50% 是参考线与诊断指标，不是及格线。** 高于它说明版面利用充分；
低于它只说明"这一页的证据确实排不满"（高瘦图、近方形图、必需的图确实多），
**只要证据清单合理、关键证据可读，就照常交付**并在交付说明注明数值与原因。

文字是图的注解，不是主体。取到最大仍低于参考线时，**只做一步判断**：

**① 这一页有没有"相关但非必需"的图？** 有 → 移走重排（凑数本来就在第 2 步被禁止，
动它不算为排版改科学）；
**② 没有 → 接受当前排布**，在交付说明注明该页数值与原因，到此为止。

不要压缩图片，不要塞不相干的图，**更不要为凑数字删必需证据或拆散同一问题的证据**。

**图内文字大小不参与这里的任何判断**（那是第 4 步）——它既不是拆页的理由，也不是拼页的借口。

### 0.5 文字层级（写大纲时就定级）

内容文字**只有 4 档字号**，**末档 = 14pt**（下界）。完整规范见 `typography-spec.md`；
大纲阶段只需做一件事：**给每条文案标上它属于哪一档**，让用户在确认大纲时就一并确认层级。

| 级别 | 角色 | pt |
|------|------|----|
| L1 | 页面主句（分节页标题、结论条、take-home） | 26 |
| L2 | 页内小节标题 / 要点组标题 | 22 |
| L3 | 正文要点（bullet 主句） | 20 |
| L4 | 依附性子项 / 限定补充；图注 / 引用 / 来源注 | **14** |

定级用**顺序判定流程**（`typography-spec.md` §2，命中即止）：
① 是这一页的标题或唯一主张？→ L1 ② 下面有从属于它的内容？→ L2 ③ 独立成句、删了论证链就断？→ L3
④ 必须依附上一级才读得通（子项、括注、`n = 3`），或在解释图与出处而非论断？→ L4
⑤ 都不命中 → **这条不该出现**，删掉或并入上一级。

约束：**一页最多 3 级**（模板标题占位符的字号不计入）；同页同级字号完全一致；**层级与字号不得倒挂**
（组标题 > 正文 > 图注）；不许为塞下版面把某条降级或单独缩小——放不下就删字或拆页。

### 0.6 Introduction 的外源配图

Introduction 讲背景常需要**本文之外的图**（引用文献的示意图/领域概览图）：

- 先 WebSearch 获取；拿到就走正常子图裁剪流程。
- **搜不到 / 无法联网时，建占位框而非留空或删页**：占位框内写"这张图要说明什么"（L4 正文色）
  + 一行**搜索关键词**（`search: "..."`，L4 次要灰）；占位框**正下方**放**引用信息占位**
  （L4 次要灰），格式 `(Ferreira Castro et al., 2020)`。
- 配图占位与引用占位**成对出现**；大纲该页标注 `外源图待补`。

## 1. Cover（1 页）

- 文献完整标题（原文）
- 作者列表（一作在前，**通讯作者只用 `*` 标注**；共同通讯都加 `*`）
  - ⚠️ **封面不要写角色括号说明**：`(* joint senior authors)`、`(* corresponding authors)`、
    `(* these authors contributed equally)` 之类一律不写，封面只留星号。
    身份/角色统一到 Author Introduction 页说明。
- 期刊名 年份 DOI
- 汇报人姓名 汇报日期
- 模板规定的封面版式（logo/院系名等）

## 2. Author Introduction（按需，0 或 1 页）

**先问"这一页对听众有用吗"。** 普通组会/短时汇报：不单独成页，封面标作者、单位、期刊、年份即可；
领域奠基工作、或作者前作与本文假说直接相关时才做（判据见 `SKILL.md` 3.8）。

**成页时的版式：并列多栏（columns），不是左图 + 右长文。**

- 主要作者（一作 + 通讯作者，通常 2–3 人）**每人一栏**，栏宽相等、水平等距。
- **每栏自上而下五要素**：
  1. **照片**：头像照（无则虚线占位框 + "photo placeholder"，占位框在栏内居中）
  2. **姓名**：英文全名，21pt（L2）；通讯作者用强调色（如 `#1E40AF`）
  3. **角色**：`First author` / **`Corresponding author 单位`** — 一律用 **corresponding author**，
     ⚠️ **不得写 "senior author"**
  4. **单位 / 履历**：一行（现单位、职业轨迹），15pt 次要灰
  5. **研究方向**：一句话（如 "structural biology of membrane proteins"），15pt
- **页下 1/3 放"相关研究脉络"时间线**，横跨整页（推荐左右两栏 3 + 2 条）：
  3~5 条时间线式要点，讲清该作者（尤其是通讯/一作）此前的关键工作如何一步步引出本文；
  **本文那一行加粗或用主色强调**。例：
  - 2018, Nature — 首次解析 X 蛋白结构
  - 2020, Science — 发现 Y 现象但机制不明
  - **本文 2024** — 补上机制缺环
- 本页属**豁免页**（不受正文 ≤30 词与图占比约束），但仍要精简、留白优先。

## 3. Introduction（页数由任务定，1 页起）

**不设"至少 3 个角度 / 2–5 页"的硬指标。** 四项任务完成即可收尾，一页装得下就一页：

1. **为什么重要**：生理/临床/产业意义，一句话能立住就不铺陈。
2. **已知什么、主流解释是什么**：不要只列"前人做了什么"，要说清**结论之间的关系**——
   哪些已确立（有独立重复）、哪些只是共识、哪些仍有争议。
3. **缺口或矛盾**：现有解释哪里不够 / 与新现象冲突 / 技术瓶颈在哪。
4. **本文要解决什么、怎么检验**：一句科学问题 + 假设 + 策略概述（可配 graphical abstract）。

判断口径：**听众能否不查资料就接上 Results 第一页**，而不是背景看起来够不够厚。
最后一页的问题必须与 Results 的大问题一一呼应。

**背景预热**：如果 Results 里会出现 ≥3 个听众不熟悉的名词（新的细胞类型、通路、器官系统、
模式生物），在 Introduction 末尾补一页 3–5 条的背景页——比在每页图注带上排三行解释更省听众的理解成本。

### 3.1 做"模型/流派对比页"时：先检验两条主张是否在同一层面

否则会画出**伪对立**，把并非互斥的观点写成"两派对峙"，是文献汇报最常见的硬伤。

- **先分清三个层次**，它们是正交的，可独立取真或取假：
  1. **标志物特异性** —— 某 marker 能否特异标记某群细胞；
  2. **功能存在性** —— 该功能/细胞群到底存不存在；
  3. **来源或身份** —— 该群细胞从哪来（预先存在 vs 由他者转化）。
  不要用一条 `Model A ←→ Model B` 的轴去表示跨层次的分歧。
- **判定方法**：把每个"模型"写成**完整命题（含"且"的合取句）**，再逐条检查对方的反驳命中哪一条。
  若只命中合取句的一部分——例如命题是"存在储备池 **且** Bmi1 标记它"，而反驳只推翻了后半句——
  则两者**不是**互斥立场。此时页面应改成"**两个可分的问题**"（各带自己的结论与引用），
  而不是"两派谁对"；真正对立的那一条再单独列出。
- **标题句式**：用 "Two separable questions" / "The genuine disagreement is …"，
  避免 "A versus B" 这种暗示互斥的写法；左右两栏宜设为"**假说 vs 观测**"而非"立场 vs 立场"。
- **引用消歧**：写 `作者 + 年份 + 期刊`（如 `van der Flier et al., Cell 2009`），
  **不要只写 `van der Flier et al., 2009a`** —— 同一组 2009a/2009b 编号在不同期刊的参考文献表里
  可能指代完全相反的两篇论文。
- **留收敛出口**：若领域后来收敛到更高层的解释（如"细胞可塑性"取代"固定谱系"），
  对比页应留一句指向该收敛点，并在 Discussion 里交代**本文结论的解释力边界**
  （本文的设计能否区分上述层次 3 的两种来源；若不能，明确写出来）。

## 4. Method（可选，0~3 页）

- 只讲**重要且有创新性的方法**；常规方法（Western blot 等）不单独成页
- 每个方法页说清：方法原理（一张示意图最好）、解决什么技术难题、为何旧方法不行
- **必须交代"为什么是这个策略"**（B 档：Method 页本身是 C 档，但成页后这条必答）：
  本文在可选的若干方案里为什么挑了它
  （分辨率 / 通量 / 生理相关度 / 可行性 / 时效……），**并点出被放弃的备选方案是什么、它差在哪**。
  只讲原理不给取舍的方法页，听众判断不出这一步到底贡献了多少。
  写法：一句结论 + 一行对照，如 `Chosen: endogenous tagging, avoids overexpression artifacts`
- 如果创新方法本身构成核心贡献（如新算法/新成像技术），可前置并加重篇幅

## 5. Results（核心，页数最多）

**严格按 §0.3 的四步走**（本节是它在 Results 里的具体化；回退仅限三类科学理由）：

1. **先写死每页的问题**：把每个大问题下的子问题写成**完整问句**（此步先不碰任何 Fig 编号）。
2. **再收"证明它需要的子图"**：读 Figure Legends，逐张子图问"它在为这个结论提供证据吗？"——
   只收**必要证据**与**配套证据**（`Fig S#x`）；答"否"的一律不收（凑数），
   而后反向查这一页的**证据链是否齐**。
3. **然后做体检（不是配额检查）**：＜2 张时先确认"是不是与相邻页同一个问题"——是则合并，
   不是就独立成页；＞4 张时先确认"有没有可独立成问的子问题"——有则拆，没有就保留多图页。
4. **最后才写 `Layout`**：在已经定死的页里选 `1x3` / `1+2` / `2x2` 把图做到尽可能大且易读。
   **`Layout` 不得改变第 2 步的证据清单**；图占比只是诊断指标，不得为了它反向改清单。

组织规则：
- **以大科学问题分节**：每个大问题前放一页 section divider（如 "Part 1 — How is X activated?"），节内页面顺序即论证链顺序
- **以小科学问题分页**：一页回答一个问题；**图数是"需要多少证据"的结果，不是 2~4 的配额**
- **逐子图登记，按证据上页**：每一张子图都必须被审查并登记（`analysis.md`），
  但**不必都上页**——不上页的进「未上榜内容备查」并写明理由（`outline-only`）。
  上页的子图必须落在"它为之提供证据"的那一页；分组依据是"共同回答同一问题"，
  而非原图打包顺序（Fig 3a 可与 Fig 5c 同页）
- **SI 补充**：当正文子图证据不足（如主图只给了总结统计、细节在 SI）时补 SI 图，标注 "Fig S3b"
- **每张上页子图配一行「编号 + 一句话图题」，写在该子图正下方**（`Captions` 字段）：
  `fig5a — IL-13 suffices to expand Tuft cells`。写**观察**（这张子图直接测到了什么），
  不写本页结论（结论在 bullet/标题）、不写推断、不复述图上已画清的流程；≤12 词、最多 2 行。

页面内逻辑：页标题 = 这一页的问题/结论 → 子图顺序 = 论证顺序 → **每张图正下方一行
「编号 + 一句话观察」**（≤12 词，必写）→ **页面底部图注带**（名词注释行首现即写，
每页都可以有；补充行只在有实质卡点时写，见 3.6）→ 最后一条 bullet = 本页小结。
两处图注分工不同：逐图那行说"这张图是什么"，底部那行说"这页里的词和图读之前要先知道什么"，
不要写到一起。
关键试剂第一次出现且**它是本页推理的一环**时，才给 ≤12 词原理
（`DREADD (hM4Di): CNO silences neurons via Gi`），写在图注带；不要只在讲稿里解释，
也不要写成正文句中的括注。

**反模式（一旦出现就是走错了方向）**：
- 标题写成对图的概括而非对问题的回答（"Fig 3 structural analysis" ✗ / "Each protomer clamps HDAC1 with a different loop" ✓）
- **先想"这页放几张图"，再补一个问题**（顺序反了：图数必须是第 2 步的产物）
- 把"相关但非必需"的图放进页面（凑数，也是图占比不达标的常见真凶）
- 把同组子图拆开到两页，只为让某张图变大或图内文字变大
- 把不同问题的子图拼在一页，只为把图占比做高
- 因为图内文字偏小就删掉一张子图（先判断是不是"关键证据不可读"，是则换布局，不是则记录）

## 6. Discussion（2~4 页）

四要素必须齐全，每要素单独成页或合并但标题清晰：
1. **Key Innovations**：最重要的创新点 ≤3 条（方法创新 / 发现创新 / 概念创新分角度提炼）。
   **每条补一句 why it is high-impact**——它把领域此前做不到的哪件事变成了做得到
   （"此前无法在活体分辨 X 与 Y" / "把该结论从相关推进到因果"）。
   只写"首次做了 X"而不写它带来什么能力变化，等于没说清创新在哪。
2. **Key Findings**：最重要的发现 ≤3 条（回应 Introduction 提出的问题，形成闭环）。
   若阶段 3.0 已确认 take-home message，它**原样**作为本页首条出现，不得改写。
3. **Limitations**：实验设计的不足之处。**素材来自 Figure Inventory 的 Hole 列，逐条汇入**
   （见 `figure-and-author.md`「Holes → Limitations 的汇入」），不要在本页现凑。
   **按影响程度排序，不按发现顺序**：`decisive` 在前（结论要退一步的），`bounded` 次之，
   `cosmetic` 不上页。每条写"缺什么 + 补上会不会改变结论"，而不是只写"未做 X"。
   兜底检查角度：样本量与统计功效、对照完整性、模型系统局限（细胞/动物 vs 人体）、
   因果性论证强度、可重复性、测量偏差。**每一条都要能追溯到某张子图，追溯不到的删掉**。
4. **Future Directions**：未来研究方向，与 limitations 逐条呼应为佳
5. **（可选，时间富余时）拓展讨论**：文献之外的内容，**必须与上面四要素分开成页或单独成节**，
   并在页面标 `Beyond the paper`。可选四个方向：
   ① 感兴趣的点与领域争议；② 文献不足与"如果重做会怎么设计"；
   ③ 可执行的后续实验（体系/读出/预期结果）；④ 转化与成药可行性（靶点可及性、选择性、
   正常组织表达带来的安全性问题、已有药物或临床进展）。
   有外部依据的给引用，纯推测写明是推测；**不得混进 Key Findings**。
   文献单薄、讲不满时长时，这一节是补时长的正当手段（而不是放慢语速）。

## 7. 收尾（可选，1 页）

Summary / Take-home message（一句话核心结论）/ 致谢，按用户要求取舍。

## 常见错误

| 错误 | 后果 | 纠正 |
|------|------|------|
| **先定"这页放 3 张图"，再补一个标题** | 顺序反了：图数变成配额，标题只能去概括图而不能回答问题 | 回到 §0.3 第 1–2 步：先写死问题，再收"证明它需要的子图"；图数是**产物** |
| **为凑图占比把不相干的子图拼一页** | 一页答了两个问题，论证链断裂 | 回 §5 第 1–2 步按问题重新收证据；图占比留到 `Layout` 里解决 |
| **为了让图占比过 50% 而删必需证据或拆散同一问题的证据** | 结论悬空，且违反"图占比优先级低于科学完整性" | 图占比是诊断指标：取到布局最大值即可，低就注明，不动证据清单 |
| **给"相关但非必需"的图留位置** | 凑数；且正是图占比不达标的常见真凶（图多了每张都变小） | 逐张问"它在为这个结论提供证据吗？"，答"否"就移走 |
| **为让某张图/某段图内文字变大而拆散同组** | 同一问题的证据被切到两页，听众要自己拼 | 拆页的合法触发点：① 这页其实是两个问题；② 证据 > 4 张且其中确有可独立成问的子问题；③ 阶段 2 发现证据链断。图大字小**不是**触发点 |
| **因为图内文字偏小就删子图 / 换图** | 破坏证据链，且多半不是真问题 | 先判"关键证据是否可读"：可读则记录；不可读则换布局（`layout-spec.md` 五 5.1），不是删图 |
| 按原文 Fig 顺序而非科学问题组织 Results | 汇报变成"看图说话" | 先建科学问题树再映射子图（§5 四步） |
| 漏掉子图 | 证据链断裂 | 用图片清单逐项勾验 |
| Introduction 只罗列"前人做了什么" | 听众看不出缺口在哪，问题显得突兀 | 按 §3 四项任务写：重要性 → 已知/共识/争议 → 缺口 → 本文问题与检验 |
| Method 讲成实验操作手册 | 篇幅失控 | 只讲创新方法及其解决的难题 |
| Limitations 写成缺项清单（"未做 A、未做 B"） | 听众无法判断哪条真的动摇结论 | 每条标影响程度：`decisive` 前置、`bounded` 次之、`cosmetic` 不上页 |
| 页标题无信息量 | 听众抓不住主线 | 全部改为科学问题/结论句式 |
| Bullets 不标层级，或一页列出 4 种以上字号意图 | 生成阶段只能"调到塞得下"，出现十余种字号、层级倒挂 | 大纲阶段按 `typography-spec.md` 定级，一页 ≤ 3 级，末档 14pt |
| 用 `·` `\|` `•` 这类装饰性符号分隔短语 | 一眼看出是机器生成的文案 | 分隔只用空格（`期刊名 年份 DOI`） |
| 不确认讲述方式就直接写大纲 | 该用倒推的场合写成流水账，或反之 | 先走 §0.2，问清 sequential / backward / hybrid |
| 把读图笔记整段搬进图注 | 图注挤掉结论；正文词预算爆掉 | 按 `figure-and-author.md`「哪些上 PPT、哪些只留大纲」筛选，其余进「未上榜内容备查」 |
| **图题写成结论、或与 bullet/页标题重复** | 一页出现两遍同一句话，占版面还容易越级（L2 措辞配 L1 观察） | 图题只写"这张子图直接测到什么"，观察句式、≤12 词；结论留给 bullet |
| **有子图却没有图题（或图题只写 `Fig 5a`）** | 听众看完图不知道该把它当什么证据 | 每张上页子图正下方一行：编号 + 一句话观察；`Captions` 字段逐图登记 |
| **给每条 bullet 都套模块框** | 全框等于无框，一页切成七八个色块，最像模板 | 只在 ≥2 个并列模块或结论块时用，每页 ≤3 个；见 typography-spec.md「模块块」 |
| **新名词裸奔**：基因/蛋白/细胞/器官首次出现不给背景，缩写不展开 | 听众要停下来想"这是什么"，直接掉队 | 首现就在页底图注带写一行 `名词: ≤10 词说明`（同页多个合并、`;` 分隔）——**这条每页都可以有，不设频率上限**；缩写按 SKILL.md 3.6 规则（全文 >3 次或 `缩写：全称（翻译）` 展开）；同页 ≥3 个新名词就加背景页 |
| **补充行复述正文**：图注带写了一句和 bullet / 结论卡同一意思的话 | 页底变成第二份正文，图变小、视线来回跳，听众什么也没多得 | 删。B 类补充行只回答"不写会让听众读错图或判高结论"的那一格（3.6 三类冗余） |
| **补充行复述图**：把 x 轴、分组、流程再写一遍 | 图上已画清，写一遍等于没写 | 删；只补图上没有的（决定性对照、n、易误读点） |
| **新名词背景写成句中括注**（`Lgr5 (intestinal stem-cell marker)` 塞在 20pt bullet 里） | 一框一号被破坏：要么混字号违规，要么括注被放大到与主句同重，还要吃掉 30 词预算 | 注释一律移到 `cap-band`，正文只留名词本身（`Lgr5+ stem cells` 这类限定语用法不算注释） |
