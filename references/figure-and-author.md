# Figure Analysis & Author Research — 图片清单规范与作者调研规范

> **档位**：「所有子图都要被审查与登记」、核心五列填满、上页与否按三档粒度判定属 **A 档**；
> 三问的深度、三级深度分级属 **B 档**；**作者调研与作者页是否成页属 C 档**（按场景决定，
> 普通组会不做——见 `SKILL.md` 3.8）。冲突裁决见 `SKILL.md` 开头「规则优先级总表」。

## 一、图片清单与子图映射（Figure Inventory）

### 建立清单

通读 Results 与 Figure Legends，为**每一张子图**登记一行：

| 字段 | 说明 | 示例 |
|------|------|------|
| 子图 ID | 图号+字母，保持与原文一致 | Fig 2c |
| 展示内容 | 实验类型 + 数据对象，一句话说清做了什么 | ChIP-seq of H3K27ac at enhancers |
| 回答的小问题 | 对应科学问题树节点 | Which enhancers are activated? |
| **实验设计** | 怎么做的 + 对照/参照是什么、够不够 + **该对照排除了哪种解释**（阴性/阳性/救援各排除了什么） | H3K27ac ChIP vs IgG and input; untreated littermate |
| **重复与独立性** | ① 重复类型：生物学重复 `n` / 技术重复 `n` / 独立批次数；② 独立性：是否与同页其他子图共用同一批动物、同一次实验、同一个模型 | `bio n=6 mice, 2 cohorts; tech n=3` / `shares cohort with Fig 2b` |
| 一句话结论 | 该子图证明了什么 | Enhancer X gains H3K27ac upon treatment |
| **结论等级** | L1 观察 / L2 关联 / L3 因果 / L4 机制（判据见 `claim-evidence-spec.md` §1） | L2 |
| **Hole / 局限** | 这张图撑不住的地方：缺对照、单时间点、n 偏小、相关而非因果、模型局限……真的没有才写 `—` | n=3, single timepoint; no rescue arm |
| **影响程度** | 这个 Hole 是否动摇核心结论：`decisive`（结论不成立）/ `bounded`（结论范围收窄）/ `cosmetic`（不影响） | bounded |
| 深度分级 | A 核心证据 / B 配套证据 / C 背景辅助，见下「三级深度」 | A |
| 页面归属 | 初步分配到的 Results 页；不上页的写 `outline-only` | Part 1, Slide 9 |
| 上榜方式 | 该图在本页的呈现粒度，见下「哪些上 PPT、哪些只留大纲」 | `panel` / `caption-only` / `outline-only` |
| 备注 | 是否需 SI 配图、是否需裁切拼合 | pair with Fig S4b |

**实验设计、重复与独立性、结论等级、Hole、影响程度五列是期刊俱乐部（JC）汇报的核心，
不要留空、不要一律写 `—`。**

逐图问**三问**（Why this experiment / What did it show / What does it establish）：

1. **Why this experiment?** —— 它要区分哪些竞争性假说？为什么上一个实验还不够？
   答句里要同时给出**实验设计**（体系 + 关键操作 + 对照）。没有对照就写 `none reported`，
   这本身就是要报给听众的信息。判定标准是"对照够不够支撑这个结论"。
2. **What did it show?** —— 直接测到什么：方向、效应量、分布、`n`（**生物学重复**，
   技术重复另标，见下「重复与独立性」）。
   不要写"显著升高"，要写"42% vs 78%，n=6，p<0.01"。
3. **What does it establish?** —— 它排除了哪些解释、留下哪些可能？据此定**结论等级**（L1–L4）。
   这一问的答案必须进入 `claims.md`，不能只停在读图笔记里。

> **Hole 列不是让你删图或换图。** 有漏洞的图依然是必要证据——把限度和结论一起讲出来，
> 才是 JC 汇报区别于"背摘要"的地方。发现漏洞默认不改分页；
> **例外**：若漏洞直接推翻了该页结论的等级（L3 掉到 L2），属于允许的回退②（证据链断），
> 按 `SKILL.md` 开头的回退规则处理并记录修订原因。

### 重复与独立性（不要只写 `n=3`）

`n=3` 是最容易被误读的三个字符：它可能是 3 只小鼠，也可能是同一只小鼠的 3 个技术重复，
还可能同一个队列被 5 张图反复引用。**这张列要回答的是"这个结论被独立验证过几次"。**

| 填什么 | 判据 | 例子 |
|---|---|---|
| **重复类型** | 生物学重复 = 独立的生物个体/独立培养/独立队列；技术重复 = 同一样本的重复测量、同一样本的多次上机 | `bio n=6 mice, tech n=3 replicates/sample` |
| **独立批次数** | 结论是否在 ≥2 个独立实验批次/独立队列中重复过 | `2 independent cohorts` / `single batch` |
| **共源性** | 是否与同页或同节其他子图**共用**同一批动物、同一次实验、同一个模型 | `shares cohort with Fig 2b` / `same scRNA library as Fig 1d` |

判读规则：

- **技术重复不能支撑生物学结论。** 同一只鼠测三次，统计上 n 变大，证据强度不变。
  清单里只写生物学重复数；技术重复单独标出，说明它降低的是测量噪声而非抽样不确定性。
- **共源性会削弱"独立验证"的说法。** 若 Fig 2b/2c/2d 都来自同一次 scRNA-seq 建库，
  它们在证据链上算**一条**证据，不是三条。此时：清单里标 `same library as Fig 2b`，
  并在 `claims.md` 的 Evidence strength 里写明"多个读出源自同一批数据"。
- **原文没写清时标 `unspecified`**，不要凭领域惯例补全（这是 `claims.md` 里
  必须标 `unverified` 的典型情形）。图上读不出的重复信息，写进 Hole 列。

> 这一列是 `SKILL.md` 5.1「统计与定量：区分生物学重复与技术重复」的承载字段。
> 没有它，那项检查就没有落点，只能靠自觉。

### Hole 的影响程度（不要只罗列缺项）

每条 Hole 必须标一档，否则 Limitations 会退化成"没做这个、没做那个"的清单：

| 档 | 判据 | 去向 |
|---|---|---|
| `decisive` | 结论不成立或必须降级 | 进 Limitations **首条**，并在页面措辞上退一步 |
| `bounded` | 结论成立但范围收窄（如只在小鼠、只在一个时间点） | 进 Limitations，同时写进 Confidence boundary |
| `cosmetic` | 不影响结论，只影响完备性 | 只留备查，不占 Limitations 版面 |

**"没有报告某项信息" ≠ "实验有缺陷"；"没做某个实验" ≠ "结论不成立"。**
判影响程度时问一句：补上这个实验，结论会变吗？会 → decisive/bounded；不会 → cosmetic。

### Holes → Limitations 的汇入（B 档）

Figure Inventory 的 **Hole 列是 Discussion 的 Limitations 页的唯一素材来源**，不是两份独立的清单：

- 写 Discussion 前，把 Hole 列里的条目**逐条汇入** Limitations 页，合并同类项后分条呈现；
- 反向核验：Limitations 里每一条都必须能追溯到某张子图的 Hole（或明确写出"全 deck 级的系统局限"）；
  **追溯不到的条目说明是凭空写的**，删掉；
- Future Directions 与 Limitations 逐条呼应（见 `outline-spec.md` 的 Discussion 规范）。

这样 Limitations 是"读图时就已记录下来的批判"，而不是写到 Discussion 才回头硬想的套话。

### 三级深度（决定花多少力气，不决定上不上页）

| 级别 | 对象 | 分析深度 |
|---|---|---|
| **A 核心证据** | 直接支撑主结论的关键图 | 完整：设计、重复与独立性、结果、效应量、替代解释、证据边界；讲稿另附答疑（`script-spec.md` §3） |
| **B 配套证据** | 对照、验证、统计、补充数据 | 核验：是否支持 A，与 A 有无矛盾 |
| **C 背景/辅助** | 示意图、重复性展示、次要发现 | 只记作用与出处，按需上页或备查 |

分级看的是**它在论证里的位置**，不是图有多漂亮、也不是它占多大版面。
一篇论文的 A 级通常只有 3–6 张；全是 A 等于没有分级。

### 哪些上 PPT、哪些只留大纲

**逐图三问的结果是"读图笔记"，不是"页面文案"。** 三问全部答完、留在 Figure Inventory 里，
但**只有一部分需要写进 PPT**——剩下的留在 `analysis.md` / `outline.md` 里供用户查阅即可。

三档呈现粒度（登记在清单的「上榜方式」列）：

| 粒度 | 上 PPT 的内容 | 留在文档里的内容 |
|------|--------------|-----------------|
| `panel`（默认） | 子图本体 + **图正下方一行「编号 + 一句话观察」** | 实验设计与 Hole 按下面的规则取舍 |
| `caption-only` | 子图本体 + 图题**只写观察句** | 实验设计写进底部图注带会挤掉结论 → 留大纲 |
| `outline-only` | **子图不上页**（属 SI / 已由相邻子图代表 / 结论已由同页主图承载） | 全部留大纲，供用户核对并解释为何不上页 |

**「编号 + 一句话观察」是每张上页子图的标配，不是可选项**（`outline-only` 除外）：

- 形式：`Fig. 5a  IL-13 suffices to expand Tuft cells`——编号与原文一致（大小写、有无句点照抄），
  后接一句 ≤12 词的观察句，**紧贴该子图下沿**（不是页面底部那一行）；
- 写**观察**（这一张子图直接测到什么），**不写结论**（结论在 bullet / 页标题）、
  **不写推断**、**不把相邻子图的结论并进来**；
- 图上已画清的处理流程、时间轴、分组名不再念一遍；
- 一句说不完说明它其实是两条证据，回上面「子图分组与分页规则」重新看分组，
  不要靠把图题写成三行解决。

排版几何（0.30 in 一行、命名 `cap-fig5a`、与底部图注带的分工）见 `layout-spec.md`
「子图标签与图题」。图题属 L4 = 14pt，不计入正文 30 词预算，但**一页合计 ≤40 词**。

**该留在大纲、不要上 PPT 的**：

- **图上已经画出来、一眼能看懂的"操作细节"**——仪器型号、抗体货号、裂解缓冲液配方、
  时间点递增序列这类。图上写着 `4 h / 8 h / 12 h`，就不要在图注里再念一遍
  （但**实验设计的骨架仍要写一行**，见下"该上 PPT 的"第一条）；
- **同页多张子图共用的实验设计**——写一次即可，不要每张图注都重复；
- **对结论无影响的对照细节**（正常 IgG、常规 input 这类"本来就该有"的对照）；
- **`n` 值之外的统计流水账**（检验方法、软件版本、P 值精度）；
- **已经写进 bullet 的结论**，不要在图注里再说一次。

**该上 PPT 的**（这些不讲，听众就要自己去猜去想，会直接掉队）：

- **新名词的注释**（A 类，**首现即写，每页都可以有**）——基因、蛋白、细胞类型、组织器官、
  模式生物首次出现时，**在图注带写一行 ≤10 词的说明**（`Lgr5: intestinal stem-cell marker`）。
  判据只有"这个词在本页之前建立过没有"，**不设频率上限**；背景页 / 前文讲过的后续不重复。
  **不写成正文句中的括注**（正文框一框一号，20pt + 14pt 括注同框即混字号违规；
  `Lgr5+ stem cells` 这类限定语用法不算注释）。
  缩写按 SKILL.md 3.6 规则使用（全文出现 >3 次，或图注带给 `缩写：全称（翻译）` 展开，否则写全称）；
- **瓶颈行**（B 类，默认没有）——只在"不写会让听众读错图或判高结论"时才写，放图注带或页首 kicker。
  按 SKILL.md 3.6 三问从三个候选里选最实质的一条：读图钥匙
  （`Cleaved caspase-3 marks apoptotic cells only`）、逻辑前提
  （`Deletion is ILC2-specific; DCs untouched`；体系句 `Tamoxifen-induced Cre; littermate controls`
  只有当体系本身就是听众的卡点时才参选）、易误读点（`Panels b-d share the same 3 donors`）。
  三问都查不到就不写——**没有瓶颈行的页比硬写一行更常见**；
- **关键试剂/技术的原理**（B 类，它是本页推理的一环才写）——为什么它能起作用，≤12 词，写进图注带该行：
  `DREADD (hM4Di): CNO silences neurons via Gi`、`degron: auxin recruits TIR1, proteasome-degrades`；
- **结论赖以成立的关键对照**——缺了它结论不成立，或该对照本身很反直觉
  （如 `no rescue in IgG arm`、`signal lost in input`）；
- **读者会自己发问的"反常识对照"**——图上不显眼但听众一定会追问的；
- **直接削弱结论的 Hole**——必须讲，但**不放在 Results 页**，汇入 Discussion 的 Limitations；
- **`n` 与统计**——`n=3` 这种量级信息建议保留在图注（L4 档，不占词预算大额）。

> **判断口径**：问两句——① **"这句不写，听众会不会误读结论或错判证据强度？"**
> ② **"这句不写，听众能不能自己看懂'怎么做的、为什么这么做'？"**
> 任一为"会"→ 内容要上页。**但两类行的门槛不同**：名词注释行（A 类）按"首现"判断，
> 首现就写，每页都可以有；补充行（B 类：瓶颈 / 试剂原理）另加一道"不写会不会读错图 / 判高结论"，
> 只会"少知道一点"的不算，**复述正文 bullet、复述图上已画清的、解释常识的一律删**
> （SKILL.md 3.6 的三类冗余）。
> 判断的是**内容**，不是页底有没有字：图注带里有补充行的页应**少于 1/3**，
> 而名词注释行不计入这个比例。
> 页面正文区仍受 ≤30 词约束，但**预算先给理解性信息**，先删修饰与重复，不删瓶颈句。

### 子图分组与分页规则

> **"先定问题、再收证据"是这个 skill 里优先级最高的一步。** 顺序是：
> **① 这一页是什么问题 → ② 证明它需要哪些子图 → ③ 才谈排版（图占比取到布局允许的最大值，
> 50% 只是参考线）→ ④ 最后才是图内文字可读性。**
> ①②定下之后**不得为排版而回头改写**：
> 不许为凑图占比把不相干的子图拼页，也不许为让某张图变大或字变大而把必需的图拆散。
> **但有三类科学理由可以回退**（问题定义错 / 证据链断 / 有未处理的竞争解释），
> 每次记进大纲「修订记录」。详见 `SKILL.md` 开头的「每一页的四步决策顺序」。

1. 收证据的依据是"**它在为这个结论提供证据吗**"，只收**必要证据**（拿掉结论就少了支撑）
   与**配套证据**（对照 / 统计 / 原始数据，多为 `Fig S#x`）——**"相关但非必需"的一律不收**。
   **允许跨原图编号组合**（Fig 3a + Fig 5c 同页合法，只要它们证明的是同一个结论）
2. **图数是第 2 步的产物，不是配额。** 2–4 张只是**诊断指标**，命中时先自问再动手：
   - ＜2 张 → 它和相邻页是同一个问题吗？是则合并，不是就**让它独立成页**
     （前提：它自己有独立问题，且证据足够决定性，如高分辨率结构、单张决定性成像）；
   - ＞4 张 → 里面有没有可以独立成问的子问题？有则拆页，没有就**保留多图证据页**。
   **不要砍证据来凑数，也不要为了凑张数硬拆。** 唯一的硬约束是证据的必要性。
3. **页面标题写问题，每张子图配自己的一行图题**（`Fig. 5a` + 一句观察，≤12 词）。
   两处不重复：标题说的是"这一页在问什么"，图题说的是"这张图直接测到了什么"；
   不要用页面底部一行笼统概括代替逐图图题（听众对不上哪句话在说哪张图）。
   写法与几何见 `layout-spec.md`「子图标签与图题」。
4. 原文的 graphical abstract / model 图通常适合放在 Introduction 末页或 Discussion 的 Key Findings 页
5. SI 图补充时机：主图缺统计细节、缺对照、缺原始数据时；在大纲中标注 `Fig S#x` 以便与正文图区分
6. 分组时**先写问题、再往里收证据**（自顶向下），而不是"把相邻图凑成一页再补一个标题"（自底向上）。
   后者是"看图说话"式 deck 的根源：标题变成对图的概括，而不是对问题的回答
7. **页数不是约束，问题的完整性才是**。不要把"页数上限"当成拆问题的理由；
   页数只是第 1 步切出多少个问题之后的自然结果

### 覆盖性核验

大纲完成后，把清单中每个子图 ID 在大纲里检索一遍：

- **每一张都必须有归宿**——要么在某一页，要么在「未上榜内容备查」里并写明理由；
- 既不在页面、也不在备查里的，视同漏读，必须回读原文补登记；
- 注意"全部审查"不等于"全部上页"：`outline-only` 是合法归宿，漏登记不是。

### 子图裁剪取材

- 单子图且 manifest 中有对应嵌入图 → 直接使用嵌入图文件，无需裁剪
- 矢量图 / 多子图组合图 → 用 `scripts/crop_figure.py` 按百分比坐标裁剪（先看整页渲染图定位坐标，裁后复核边界，不准就微调重裁）
- 坐标为页面宽高的百分比（左上原点），与渲染 DPI 无关；输出文件名统一 `fig<N><字母>.png`，与 Figure Inventory 中的子图 ID 一一对应

## 二、作者调研规范

### 必查信息与来源

| 信息 | 推荐来源 |
|------|----------|
| 姓名/中文名 | 文献作者列表 + 单位官网 |
| 照片 | 通讯/一作所在实验室官网 Team 页、单位教职页、ORCID |
| 研究方向 | 实验室官网 About、近期论文标题聚类 |
| 工作单位/职称 | 文献通讯地址 + 官网交叉验证 |
| 研究脉络 | Google Scholar / PubMed 按年份检索该作者与本文主题相关的代表作（3~5 篇） |

### 检索策略

1. 优先调研**通讯作者**与**第一作者**（页面上以通讯作者为主线）
2. 检索式示例：`"<author name>" <topic keyword> site:edu`、`"<author name>" lab <institution>`
3. 研究脉络聚焦"与本文直接相关"的前作——讲清从 2018 → 2020 → 本文的证据链，而非罗列全部发文
4. 注意同名作者混淆：用单位 + 研究主题双重确认

### 注意事项

- **作者页的页标题固定为 `Authors`**（见 `SKILL.md` 3.8）：不是姓名、不是论文题目、
  不是 "Who are they" 一类的疑问句，也不加副标题；中文汇报同样写 `Authors`，
  与 `Introduction` / `Methods` / `Discussion` 共用一套节标签语汇。调研到的信息进栏内，
  不进标题。
- 照片仅用于内部学术汇报的作者介绍，属合理使用范畴；不要对照片做风格化处理
- 查不到照片时放灰色占位框 + "Photo placeholder" 文字，**禁止用 AI 生成人脸冒充作者照片**
- 作者信息以官方来源为准，不得依据二手自媒体内容编造履历
- 荣誉头衔（如 HHMI investigator）可写但需核实
