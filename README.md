# paper-to-slides
*人工古法手打：该skill的编写、测试、应用均使用deepseek-v4.1-Flash，未测试其他模型表现。
把一篇科研论文 PDF，变成一份**能直接上讲台**的极简英文汇报幻灯片。

不是"把论文摘要塞进模板"，而是先想清楚**每一页要回答哪个科学问题、需要哪几张图作为证据**，
再据此决定分页、排版和字号。产出物是 `.pptx`，可继续在 PowerPoint / WPS 里手工微调。

```
输入：paper.pdf  (+ 可选：你自己的 template.pptx)
输出：analysis.md → claims.md → outline.md → deck.pptx (+ 讲稿，可选)
```

- 想直接装起来用 → 看 [`INSTALL.md`](INSTALL.md)
- 想知道每一步的细则 → 看 [`SKILL.md`](SKILL.md) 与 `references/`

---

## 1. 什么时候用它

触发场景（对 agent 说其中任意一句即可）：

- 「把这篇 PDF 做成组会 PPT」「paper-to-slides，这篇 Science」
- 「做成 journal club 汇报」「文献汇报幻灯片」
- 「这篇论文帮我做成英文 slides，用我上次那个模板」

不适合：商业 BP、课程课件、需要强设计感的产品发布稿。
本 skill 的美学取向是**学术极简、看起来像人手工做的**，不追求花哨。

## 2. 核心能力

### 2.1 六阶段流程（阶段之间可暂停确认）

| 阶段 | 做什么 | 产出 |
|------|--------|------|
| **0** 任务与模板 | 先问时长/听众/目的/语言/深度取舍；再解包 OOXML 判断模板能不能用 | `template_profile.json` |
| **1** 精读与登记 | 逐图逐段读 PDF，判论文类型、登记实验设计/等级/漏洞与原文位置 | `analysis.md` |
| **2** 论证审查 | 给结论定级（L1–L4）、建主张—证据矩阵、列替代解释与结论边界 | `claims.md` ← **判断环节** |
| **3** 讲述主线与大纲 | 先问讲述方式与 take-home，再按科学问题分页 | `outline.md` ← **确认点** |
| **4** 生成 PPTX 与讲稿 | 提图 → 裁子图 → 算坐标 → 落盘；按需写配套讲稿 | `deck.pptx` / `讲稿.md` |
| **5** 双重验收 | 科学线（证据/措辞/追溯）+ 工程线（溢出/字号/词数）；图占比单独作诊断指标，不判死 | 检查报告 |

阶段 2 是这一版新增的核心：**先判断这篇论文的结论被证据支持到哪一步，再决定讲什么**。
阶段 3 结束时会**停下来等你确认大纲**；未回应前不会进入阶段 4。

### 2.2 规则优先级总表 ⭐（冲突时按此裁决）

规则分三档，**上一档压下一档**。判断不了就看它属于哪一档——不用在各章节里找"最高原则"字样，
那几处都已归位到本表（总表在 `SKILL.md` 开头，本节是速览）。

| 档 | 含义 | 代表规则 |
|---|---|---|
| **A 不可妥协** | 违反即交付失败，任何场景都不能让 | 科学完整性优先于排版；结论不越级；不杜撰可追溯；分页按问题不按图数；回退只因科学理由；用户确认门禁；产物改则新建副本；理解性信息不可删；工程硬失败必修；14pt 字号地板；不用装饰性分隔符 |
| **B 默认建议** | 通常照做；与 A 冲突时让位，偏离要写明 | 正文 bullets ≤30 词（标题不计入；核心页 40，装不下先削修饰、不削科学内容）；图占比取到最大值（50% 是参考线）；一页 ≤3 级字号；每图一条 `cap-*` 图题（必写）+ 底部图注带（名词注释行首现即写，补充行默认没有）；每页 ≤3 个模块块；各节权重；讲稿时长 90–100%；Discussion 四要素；清单核心五列填满 |
| **C 按场景决定** | 取决于时长、听众、目的、论文类型，没有统一默认值 | 作者页有无；Introduction 页数；Method 0–3 页；讲述方式（问用户）；take-home；讲稿是否产出；类型检查项取哪些；拓展讨论/收尾页；语言 |

> **另有三类纯诊断值，只汇报、永不驱动决策**：图占比数值、图内文字 `text_display_px`、
> 每页图数。它们能提示"这一页是不是排得不对"，但**不能**用来决定删哪张图、拆不拆页。

### 2.3 每一页的四步决策顺序（A 档）

这是整套方法论的骨架，**顺序不可颠倒**：

```
① 问题  这一页要回答哪个科学问题？（一句话，问句形式 → 成为页面标题）
   ↓
② 证据  证明这个问题需要哪几张子图？（必要 or 配套；张数是结果，不是配额）
   ↓
③ 坐标  这几张图怎么摆？（plan_layout.py 自动枚举择优）
   ↓
④ 记录值  图内文字渲染后多大？（只记录；只有"关键证据不可读"才触发复核）
```

**默认不回跳，但允许因科学理由修订。** 为了让图更大、字更大而回去改问题或证据归属，
是用排版反推科学——这正是"看图说话"式 deck 的成因。允许的回退只有三类：
① 问题定义错了；② 证据链断了；③ 有未处理的竞争性解释。每次回退记进大纲的「修订记录」。

**图的张数不是门槛。** 一张图若能独立回答一个问题（高分辨率结构、单张决定性成像），
就让它独占一页；六张图若同属一个问题，就保留多图证据页。2–4 张只是诊断指标。

### 2.4 批判性阅读、讲述方式与倒推构建（文献汇报专用）

普通"文献转 PPT"只做**复述**：图讲了什么、结论是什么。这套 skill 多做四件事：

**① 论文级论证审查 —— 结论分四级，措辞不许越级**

每条核心主张进 `claims.md` 的矩阵：作者主张 / 直接观察 / 推断 / 证据等级（**L1 观察、
L2 关联、L3 因果、L4 机制**）/ 证据强度 / 未排除的替代解释 / 决定性实验 / **结论边界**。
`claims.md` 会明确写出"能说到哪一步、不能声称什么"，页面标题与 Discussion 的措辞都以此为上限。
**它只审核心结论，不对每句背景做同等强度审查**——这是"读得很全但没讲透"的解药。

**② 逐图记批判 —— 实验设计与 Hole，并标影响程度**

Figure Inventory 里每张子图登记**为什么做这个实验、看到了什么、因此确立了什么**、
实验设计与 Hole。每条 Hole 还要标影响程度：`decisive`（结论不成立）/ `bounded`（范围收窄）/
`cosmetic`（不影响）。Limitations 按这个顺序排，而不是把"没做 A、没做 B"堆一页。
图还按 **A 核心 / B 配套 / C 背景** 分三级——**所有图都要审查，但不是所有图都要上页**。

**③ 两种讲述方式由你选（阶段 3.0，会先停下来问你）**

- **`sequential` 正常顺序讲述**：按论文逻辑正向展开（Intro → Method → Results → Discussion），
  适合教学型、听众未读原文。
- **`backward` 倒推讲述**：先亮 take-home 与最强证据，再回填"为什么它能成立"，
  适合期刊俱乐部、时间紧、听众已读原文。
- **`hybrid`**：主体顺序讲，Results 开头加一页结论预览，或 Discussion 倒推收束。

选 `backward` 时会再问一句：定死**一句话 take-home message** + **1~3 张 killer data**。
确认后 take-home 原样进收尾页、killer data 优先拿最大图面积，不因排版原因被降级。
**问完才动笔写大纲**，不替你默认。

**④ 读图笔记分层：理解的必需项上页，其余留大纲**

逐图三问（为什么做 / 看到什么 / 因此确立什么）的结果是**笔记**，不是页面文案，但分两类：
**听众不懂就没法判断结论**的**内容要上页**（本页理解瓶颈、关键试剂原理、新名词背景），
**但两类内容在页底的出现频率不同**：

- **新名词背景**——首现就在 `cap-band` 写一行 `名词: ≤10 词说明`，**每页都可以有，不设频率上限**
  （正文框一框一号，塞不进 14pt 括注，所以不进正文）；
- **瓶颈行 / 试剂原理行**——**默认没有**，只在"不写会让听众读错图、或把结论判高"时才写。
  **冗余图注几乎都出在这一类**：复述 bullet、复述图上已画清的、解释常识的，一律删。

其余（货号、配方、次要对照、统计流水账）只留在大纲的「未上榜内容备查」节里供你核对。
另有 `panel` / `caption-only` / `outline-only` 三档呈现粒度，登记在清单的「上榜方式」列。

另外两处补强：Method 页必须交代**为什么选这个策略、被放弃的备选差在哪**；
Key Innovations 每条补一句 **why high-impact**（把什么从"做不到"变成"做得到"）。

### 2.5 三项硬性门禁 + 一项诊断指标（阶段 5.2 校验）

| 项 | 判据 | 脚本 |
|------|------|------|
| **文案预算** | 内容页**正文 bullets** ≤ **30 词**（**页标题不计入**，标题另受 ≤12 词约束；图注带、以及每图下方 `cap-*` 图题行也不计入），描述性短语/结论性短句 | `verify_deck.py` |
| **字号层级** | 内容文字落在 **4 档阶梯**上、单页 ≤ 3 级、无层级倒挂、**末档 14pt 即下界** | `verify_deck.py` |
| **一框一号** | 一个文字框内只有一个字号；要两个层级就拆两个框（`mixed sizes in one textbox`） | `verify_deck.py` |
| **字体** | 外文 **Calibri**、中文 **黑体**；三个 theme 的 major/minor 一致，`latin` 槽不许指 `+mj-ea` | `verify_deck.py` `[fonts]` |
| **文案符号** | 不出现 `·` `・` `∙` `•` 等装饰性分隔符，分隔短语只用空格 | `verify_deck.py` |
| **图占比**（**诊断，不判死**） | 每页取到**布局允许的最大值**；50% 是**参考线**不是及格线。低于它只打印 WARN，**不进退出码** | `plan_layout.py` 择优 + `verify_deck.py` 报告 |

**图占比为何不是门禁**：它的优先级低于"本页叙述充实、证据链完整、关键证据可读"。
高瘦图、近方形图、必需的证据本来就多——这些页排不满 50% 是几何事实，不是缺陷；
为了凑数字去删必需证据或拆散证据，代价远大于版面数字。
脚本侧：`--figure-blocking` 可恢复为阻塞，`--figure-pct-override "12=42"` 可声明某页接受值。

另有 `measure_deck.py` 专查**文字溢出与重叠**（文字跑出框、与相邻元素压叠）。
它现在把**文本框内边距**也计进可用宽高（旧版只扣段落 `marL`）——填充色块的内边距是真实空间，
不计进去会低估行数、漏报溢出。要回到旧的宽松口径用 `--ignore-insets`。

> **词预算是软上限，有具名例外**：核心证据页若 30 词装不下"设计 + 结论 + 关键数值"，
> 可放宽到 40 词（多出的词只能用于读图指引或数值），大纲标 `Budget: 40`、
> 验收传 `--body-words-override "9=40"`。**没标的页仍按 30 判**。
>
> 它守的是**版面**，不是论证：一页讲不清"做了什么、看到什么、这个证据为什么站得住"时，
> 让它变长；能压的只有修饰与复述。真空不下 → 删修饰 → 拆页，不是删实验设计与关键对照。
> 反过来，**30 词以内但 `measure_deck.py` 报溢出，也必须改**——预算是上限，不是达标的证明。

### 2.7 内容文字 4 档字号阶梯

内容文字（L1–L4）**必须**落在下表上，不允许"逐条微调字号直到塞得下"：

| 级别 | 角色 | pt |
|------|------|----|
| **L1** | 页面标题 / 唯一主张 | **26** |
| **L2** | 次级标题 / 分组标题 | **22** |
| **L3** | 正文条目 | **20** |
| **L4** | 子项 / 限定语（括注、`n=3`）；图注 / 引用 / 出处 | **14** |

判定流程（**命中即止**，顺序判定而非按大小猜）：

```
① 是页面标题 / 本页唯一主张？                        → L1
② 下面有从属内容？                                    → L2
③ 独立成句、删了论证链就断？                          → L3
④ 必须依附上一级（子项 / 括注 / n=3）或在解释图与出处？ → L4
⑤ 都不命中 → 它不该出现在这一页，删掉
```

**一框一号**：一个文字框内只允许一个字号。要「bullet + 它的括注」这种两层级，
就**拆成两个框**——层级感来自框分立与档位差，不来自同一个框里调两号
（`verify_deck.py` 判 `mixed sizes in one textbox`）。注意本 skill 里"括注"这类注释
**默认不进正文框**，而是统一放页底 `cap-band`（新名词注释常驻 / 补充行按需，见 SKILL.md 3.6）。

倒挂检测：短标签（≤4 词）比本页"正文块"（词数最多、≥6 词的非图注文本框）低一级以上 → 报
`inverted hierarchy`（L4 是末档，天然豁免）。所以**必须让图注不参与正文块评选**：
**`cap-*` 图题行按名字排除**（无论落在页面哪个高度）；**底部图注带按位置排除**（`y ≥ 6.85in` 之外
还要靠名字）——它词数通常最多，若用独立文本框且不叫 `cap-*`，就会抢走正文块的位置，
使检查失去参照、**真倒挂被漏报**。把它命名成 `cap-band` 即可。

> **L4 是唯一末档**：图注与子项共用 14pt，靠颜色区分（子项正文色、图注引用次要灰）。
> 不再有"注解专用的小字号"，**任何小于 14pt 的文字都判 FAIL**。
>
> 模板标题占位符的字号**不计入**"单页 3 级"上限（它是模板决定，不占用你选的三档），
> 否则"标题 + 组标题 + bullet + 图注"这种正常页面会被误判超限。
>
> ⚠ **不要混淆两套"字号"**：内容文字的 L4 = **14pt**，是作者**编写**的值；
> 图内文字 = `源图 px × 缩放比 × 96`，是缩放的**结果**，只记录不上报。
> 两者量级相近但语义完全不同——**不要为了修图内小字去动 type scale**。

### 2.8 页面上的两个固定视觉元素

**① 每张子图正下方：编号 + 一句话图题**

每张上页的子图都带**自己那条**图题，紧贴图的下沿，不是页面底部一行笼统概括：

```
Fig. 5a  IL-13 suffices to expand Tuft cells
Fig. 5b  KLRG1+ ILC2s expand five-fold after IMQ
```

- **写观察，不写结论**：这张子图直接测到什么；结论由 bullet 和页标题承担，重复一遍只占版面还容易越级；
- **≤12 词、最多 2 行**，L4 = 14pt 次要灰，`Fig. 5a` 加粗（同字号同色，不另起一档）；
- 规划阶段就把这行**预留进格子**：`plan.json` 写 `"panel_caption_in": 0.30`（一行）或 `0.53`（两行），
  `plan_layout.py` 会扣掉它并输出 `cap_x/cap_y/cap_w/cap_h`，生成时照抄即可；
- 命名 **`cap-<label>`**：`verify_deck.py` 靠这个前缀把它认作图注——**不计入正文 30 词**，
  也不会被当成"正文块"去比层级（否则一条长图注会把整页判成层级倒挂）。
  `[panel captions]` 段会点出"有图无题"的页。

底部图注带装**两类行，频率完全不同**：
**名词注释行**（`名词: 说明`）首现即写，**每页都可以有，不设频率上限**——这是常规写法，不是配额；
**补充行**（瓶颈行 / 试剂原理行）**默认没有**，只在"不写会让听众读错图或判高结论"时才写。
两者分工：逐图那行说"这张图是什么"（必写），底部那行说"这页里的词和图，读之前要先知道什么"。
底部按行数给 `caption_band_in`（**0 行 0.00** / **1 行 0.42**（常见）/ 2 行 0.66 / 3 行 0.90 in），最多 3 行；
一行都没有的页写 0，图区直接拿回这段高度。
**要看的比例是"带补充行的页"≤ 1/3**，名词注释行不计入这个比例。

**② 同一模块的内容：无边框填充块 + 白字**

把**同一个模块**的几条内容圈成一个视觉单元，或给一句话结论加锚点——这是唯一允许的几何强调手段：

- 圆角/直角矩形，**无描边**（`line.fill.background()`）、**无阴影**、填充 = 主色 `accent1`，
  文字纯白、字号**仍取 4 档阶梯**（不变大，加粗可以）；
- 内边距左右 ≥0.14 in、上下 ≥0.08 in；
- **白字前先算对比度**：填充色相对亮度 `L ≤ 0.175`（`1.05/(L+0.05) ≥ 4.5`）。
  主题色偏浅就用加深 30–40% 的版本——白字压浅底投影后既看不清字也丢了边界；
- 每页 **≤3 个**，只在确有 ≥2 个并列模块或一个结论块时用。**不要给每条 bullet 都套框**，全框等于无框；
- 命名 `Mod-<slug>`（**不能**以 `Rectangle` 开头，那个前缀会被算进图占比）；
- 框里的字仍是正文，**照常算进 30 词**——套框不产生任何额外文字配额。

规范分别见 `references/layout-spec.md`「子图标签与图题」与
`references/typography-spec.md`「模块块：填充底 + 反白文字」。

### 2.9 两条讲演原则（已写进流程，不靠临场发挥）

**① 听众不会思考，别让他们猜。**

新出现的基因、蛋白、细胞类型、组织器官、模式生物，第一次出现就在**页底图注带**写一行
≤10 词说明（`Lgr5: intestinal stem-cell marker`）——**这条每页都可以有，不设频率上限**。
**不写成正文句中的括注**：正文框一框一号，20pt + 14pt 括注同框即混字号违规。
关键试剂/技术在本页推理里是必需一环时，才给 ≤12 词原理（`DREADD (hM4Di): CNO silences neurons via Gi`）；
**补充行（瓶颈 / 试剂原理）按需**——只在"不写会让听众读错图、或把结论判高"时才写，
复述正文、复述图上已画清的、解释常识的一律删（SKILL.md 3.6 的三类冗余）。
体系句只有当体系本身就是卡点时才写。图注带是**字数豁免区**，不限字数，
但**按行数给高度**（0 行 0.00 / 1 行 0.42 / 2 行 0.66 / 3 行 0.90 in），最多 3 行；
**要看的比例是"带补充行的页"≤ 1/3**，名词注释行不计入。
缩写只在两种情况下可用：全文出现 >3 次，或图注带给 `缩写：全称（翻译）` 展开；否则写全称。
标准只有一个：听众不查资料，能不能读懂这页图、判断结论强度。图上画得出的不重复，
画不出的（决定性对照、时间点、n、试剂易误读点）必须补。这条**优先于文案极简**——
30 词先给理解性信息，冲突时删修饰，不删瓶颈与背景。

**② 时长是硬预算。**

阶段 0 会先问时长与页数上限（没给就按 15–20 min 并写明假设），3.0 按时长反推页数与各节权重
（Intro 15–20%、Method 5–10%、Results 50–60%、Discussion 15–20%），目标落在 **90–100%**：
超时是事故，明显过短（<70%）同样是准备不足。
时间不够 → 先合并/删页，不砍背景与设计、不加快语速；时间富余 → 按"拓展讨论"补内容
（领域争议、文献不足、可执行的后续实验、成药可行性），页面标 `Beyond the paper`，
不与文献结论混写。

## 4. 可个性化清单 ⭐

以下每一项都可以改，且**大部分改一处就生效**。

### 4.1 换模板（最常用）

模板查找顺序，前者覆盖后者：

```
1. assets/template.pptx          ← 放这里 = 项目自有模板，优先使用
2. assets/_default/template.pptx ← 包内置默认模板
3. 都没有 → 向你要
```

换风格只需一条命令：

```bash
cp /path/to/your/template.pptx .workbuddy/skills/paper-to-slides/assets/template.pptx
```

一份合用的模板至少要含**4 类版式**：封面 / 内容页（**必须带标题占位符**）/ 分节页 / 纯图页。
内置默认模板的 4 个版式是 `标题` / `小标题内页` / `question分节页` / `空白内页`，
页面尺寸 13.333 × 7.5 in（16:9）。

> 不需要预置"多子图格位"——子图由生成阶段按英寸坐标绝对定位，
> 真正决定每页能放几张图的是**可用图形区尺寸**。别把"每页只有 1 个图片框"当缺陷。
> 详细判据见 `assets/README.md`、`references/template-audit.md`。

### 4.2 改配色

在 `plan.json` 里写 `palette` 字段，生成阶段会交给
`theme_override.apply_theme_override(prs, palette)`，一次性改写所有 `theme*.xml` 的
`clrScheme` —— layout / master / slide 里的 `schemeClr` 引用会自动跟随解析。
不指定时用内置色板 `PAPER_MINIMAL`（学术极简）：

| 槽位 | 色值 | 用途 |
|------|------|------|
| `dk1` / `accent1` | `#0B0F1A` | 主文字（极简取向：用主色当"强调"） |
| `lt1` | `#FFFFFF` | 背景 |
| `accent2` | `#64748B` | 次要灰（对比度 4.76:1，过 WCAG AA） |
| `accent3` | `#94A3B8` | 辅助灰（2.56:1，仅用于大字号次要标注） |
| `accent4` | `#1E40AF` | 极少用的强蓝色，仅在需突出关键结论时 |

改色只需覆盖想改的槽位：

```python
from theme_override import apply_theme_override, PAPER_MINIMAL

MY_PALETTE = {**PAPER_MINIMAL, "accent1": "123456"}   # 未列出的沿用默认
apply_theme_override(prs, MY_PALETTE)
```

> 注意 `accent1` 是"强调色"槽位，默认与主文字同色。若你要的是"有品牌蓝作强调"，
> 应该改 **`accent1` → 品牌蓝**，而不是去动 `accent4`。
> 效果可用 `dump_palette(prs)` 打印核对。
>
> 另注：`apply_theme_override` 只改 `schemeClr` 引用。若版式里写的是**字面 `<a:srgbClr val="…"/>`**
> （很多自制母板都这样），换色板对它无效——那些颜色要么逐 run 显式设色，
> 要么用自建色块承载（详见 `SKILL.md` §4.4）。

### 4.3 改字体

在 `plan.json` 里写 `typography` 字段，生成阶段会交给
`theme_override.apply_typography_normalization(prs, fonts)`，
把 `slideLayout*/slideMaster*` 里硬编码的非主题字体统一替换成主题槽位引用。
不指定时取主题文件里已有的 `majorFont` / `minorFont`。

```json
{
  "typography": {
    "title_major_latin": "+mj-lt", "title_major_ea": "+mj-ea",
    "body_minor_latin":  "+mn-lt", "body_minor_ea":  "+mn-ea"
  }
}
```

`ea` 是东亚字体槽位——**中文不设 `ea` 会回退成系统字体**，务必成对指定。

**硬规则（v10）：外文 Calibri，中文黑体，一份 deck 只有一个拉丁族 + 一个中文字族。**
内置母版三个 `theme*.xml` 的 majorFont / minorFont 已归一化为 `Calibri + 黑体`，
master / layout 的项目符号字体也是 Calibri，`latin` 槽也没有指向 `+mj-ea`（指错会让英文
标题按黑体渲染，字距发宽而查不出是哪出错），所以**生成时不要写 `run.font.name`**——
留空即继承主题，写死反而容易写错族。

自带模板先归一化一遍（只动字体层，不动配色与字号档位），改完自动读回校验：

```bash
python scripts/normalize_template.py my_template.pptx            # 就地改
python scripts/normalize_template.py my_template.pptx --dry-run   # 只看报告
```

`Arial` / `等线` / `宋体` / `Times New Roman` 混入会被 `verify_deck.py` 的 `[fonts]` 段点名；
`Inter` 这类非系统字体在别人机器上还会**静默回退、换行错位**。

### 4.4 改版式角色映射

模板版式的名字千奇百怪，用 `layout_role_map` 告诉 skill 哪个版式干哪件事。
**内置默认模板的版式名如下**（可直接照抄）：

```json
{
  "layout_role_map": {
    "标题":           "cover",
    "小标题内页":      "content",
    "question分节页":  "section-divider",
    "空白内页":        "blank"
  }
}
```

`content` 版式**必须带标题占位符**（本母板的 `小标题内页` 有 `TITLE` + `SLIDE_NUMBER`，
无 BODY —— 正文由生成阶段显式创建文本框）。`空白内页` 只有页码占位符，只能当纯图页。

> `inspect_template.py` 给的 `kind_guess` 只是**猜**。生成阶段一律读 `layout_role_map`，
> 这样模板里出现词表外的版式名（英文 `Splash`/`Hero`、自定义命名）时也不会选错版式。

### 4.5 改字号阶梯

```bash
python scripts/verify_deck.py deck.pptx --tiers "26,22,20,14" --max-tiers-per-page 3
```

- `--tiers` — 4 档 **pt** 值（降序），想整体放大/缩小就改这一串（**单位是 pt，不是 px**）
- `--max-tiers-per-page` — 单页最多几级，默认 3
- `--no-type-scale` — 临时关闭字号检查

四档全是整数 pt，OOXML 的 `a:rPr/@sz` 以 1/100 pt 存整数，直接写 `sz="2600"` / `sz="1400"`，
不存在小数换算——**不要自行插入 15pt、17pt 这类中间档**。

### 4.6 改文案预算与图占比参考线

```bash
python scripts/verify_deck.py deck.pptx --max-body-words 30 --min-figure-pct 50 --exempt 1,2,6,9 \
       --figure-pct-override "12=42,7=38"
```

- `--max-body-words` — 内容页正文词数上限（默认 30）
- `--body-words-override` — 单页例外，如 `"3=40,7=40"`（只给大纲标了 `Budget: 40` 的核心证据页）
- `--min-figure-pct` — 图占比**参考线**（默认 50）。**低于它只报 WARN，不进退出码**
- `--figure-pct-override` — 单页接受值，如 `"12=42"`：该页证据排不满是科学原因
  （高瘦图 / 近方形图 / 必需的图确实多），声明后标 `accepted`，即使在
  `--figure-blocking` 下也不会再被判死
- `--figure-blocking` — 把图占比**恢复为阻塞项**（默认关闭；只在确实需要强约束时才开）
- `--exempt` — 豁免页（封面 / 分节页 / 作者页 / Discussion 等文字密集页）
- `--banned-symbols` — 文案里禁止出现的装饰性分隔符（默认 `· ・ ∙ •`）。
  想放行就传空串 `--banned-symbols ""`；想把 `|` 也一并禁掉就传 `"·・∙•|"`

图占比的口径是 **图面积 / 可用图区面积**——可用图区 = 内容区扣除标题带、
图注带与页边距后的净面积，**不是整页面积**。

> ⚠ 两个 `figure_coverage` 分母其实不一致：`plan_layout.py` 用已扣图注带的 content area，
> 而 `verify_deck.py` 用模板版式自带的 `figure_area`（**不扣图注带**，内置母板 74.90 in²）。
> 同一页可能前者 58%、后者 53%——这只是**读数**差异，把面积做大时按 verify 的口径自算即可，
> 详见 `references/layout-spec.md` 三。

### 4.7 改排版参数

`plan.json` 里可调的字段（全部以英寸为单位，96 DPI 换算）：

| 字段 | 默认 | 含义 |
|------|------|------|
| `slide_w_in` / `slide_h_in` | 13.333 / 7.5 | 页面尺寸（改模板后要同步） |
| `title_band_in` | — | 顶部标题带预留高度（从模板实测回填） |
| `caption_band_in` | 0 | 底部图注带预留高度（**不写图注带的页填 0**，图区拿回这段高度；要写时按行数给足：1 行 0.42 / 2 行 0.66 / 3 行 0.90 in） |
| `margin_in` | 0.3 | 页边距 |
| `gap_in` | 0.15 | 子图间最小间距（不重叠规则） |
| `min_text_px` / `target_text_px` | 18.67 / 20 | 图内文字舒适线下限/目标（14pt≈18.67px） |
| `panel_caption_in` | 0（不预留） | **每张图正下方图题行的预留高度**：一行 `0.30`、两行 `0.53`。给了它，脚本会扣掉这段再排图、让图贴底对齐，并输出 `cap_x/cap_y/cap_w/cap_h` |
| `caption_gap_in` / `caption_line_in` | 0.06 / 0.237 | 图与图题的间距 / 一行 14pt 的高度（`14×1.22/72`）。也可以不带 `panel_caption_in`，改用每张图的 `caption_lines` 让脚本自己推 |
| `panels` | — | 子图清单（`label` / `file` / `text_px` / `group` / `caption_lines`），**顺序 = 阅读顺序** |

`title_band_in` 等坐标参数应当**从模板实测值回填**（阶段 0 的
`template_profile.json` 里有），不要凭感觉填——填错会导致子图与标题压叠。

⚠ **`min_text_px` 一律写 `0`**。脚本默认会给低于舒适线的子图扣 40 分，
而覆盖率不足只扣 15 分，会让第 ④ 步的记录值压过第 ③ 步的目标函数
（实测把图占比 80% 的 `1x3-row` 判给了 59% 的 `1+2`）。
传 0 后脚本只优化"不重叠 + 图占比最大 + 留白最匀"，
图内文字大小照常打印、照常汇报，只是不再影响选型。

### 4.8 改讲稿语速

`references/script-spec.md` 的讲稿按 **≈ 230 音节/分钟**（中文正式汇报基线）换算逐页时长。
音节数 = **CJK 字符数 + 英文 token 音节数**。

如果你的语速习惯不同，改这个基数即可。实测校准供参考：
4100 汉字 + 250 英文音节 = 4354 音节 → **18.9 min @230 / 17.4 min @250**。

> 音节模型与字词模型两套口径实测相差 **< 5%**，可互换（缩写密集的稿子用音节模型更准）。
> 讲稿一律按**逐页实测音节数**换算，不凭感觉分配页时长。

### 4.9 改时长与拓展策略

时长在**阶段 0.1** 确认（3.0 只沿用，不再重复问），写进大纲头部的 `Duration` 字段，并按时长反推页数：
内容页 ≈ `时长(min) × 0.8~1.2`，另加封面/分节/作者页约 +10%；各节权重起点
Intro 15–20% / Method 5–10% / Results 50–60% / Discussion 15–20%。目标 **90–100%**。

要改默认行为，告诉 skill 三件事即可：

- **时长**：给分钟数（说明是否含提问）。没给则按 15–20 min，并在 outline 里写明假设。
- **拓展开关**：默认"时长富余才拓展"。也可以直接要求「加两页成药可行性」或「不做拓展」；
  拓展页会标 `Beyond the paper`，不与文献结论混写。
- **理解性信息的密度**：默认"新名词首现就在图注带写一行注释，**每页都可以有**；
  瓶颈行与试剂原理行只在'不写会让听众读错图或判高结论'时才写"。所以**多数页的图注带是一行名词注释**。
  若你的听众是本领域小同行，可要求「新名词只给缩写展开、不写背景说明」；
  反之给外行讲课时可要求「补充行也可以多写，允许图注带放到 3 行」。
  这两项改的是 `SKILL.md` 3.6 的默认值，不影响门禁。

## 6. 出问题怎么办

| 现象 | 看哪里 |

| 模板审查告警看不懂 | `references/template-audit.md` 判据表 + 判读陷阱 |
| 大纲格式不对 | `references/outline-spec.md` |
| 两条规则冲突，不知道听谁的 | `SKILL.md` 开头「规则优先级总表」：先看各属 A/B/C 哪一档，上一档压下一档 |
| 出现十几种字号 / 组标题比正文小 | `references/typography-spec.md` |
| 文案里混进了 `·`，`[copy style]` 报 FAIL | 把分隔改成空格，或调 `--banned-symbols` |
| 听众跟不上 / 反馈"不知道这图怎么做出来的" | `SKILL.md` 3.6 + `figure-and-author.md`「哪些上 PPT」：实验设计、试剂原理、新名词背景必须上页 |
| 讲不完 / 内容太单薄撑不满时长 | `SKILL.md` 0.1（时长）+ 3.0（反推页数）+ 3.7（拓展）；目标 90–100% |
| 结论说得太满 / 被追问"这能说明因果吗" | `references/claim-evidence-spec.md`：按 L1–L4 定级，措辞以 Confidence boundary 为上限 |
| 不知道哪些图该上页、哪些留大纲 | `references/figure-and-author.md`「三级深度」+「哪些上 PPT」 |
| 单图页被要求合并、或 6 张图被要求拆页 | 图数是诊断指标不是门槛，见 `SKILL.md` 第 2 步与 `layout-spec.md` 二 |
| 作者页要不要做 | `SKILL.md` 3.8：普通组会不做，封面标作者与单位即可 |
| 作者页的标题写什么 | **固定写 `Authors`**（`SKILL.md` 3.8）：不写论文题目、姓名或疑问句，不加副标题；`verify_deck.py` 的 `[authors page]` 段会核对 |
| 讲稿写成念 PPT | `references/script-spec.md` §2：每页要有推理桥梁与过渡句 |
| 作者简介怎么写 | `references/figure-and-author.md` |
| 交付后的 PPT 需要修改 | 一律**新建副本改**（`deck_v2.pptx` 递增），不在原文件上改——见 `SKILL.md` §4.4 |
| 想换模板 | 把模板拷成 `assets/template.pptx`，阶段 0 优先用它 |

## 7. 设计取舍（为什么这么做）

- **规则分三档，冲突按档裁决**（§2.2 总表）。不加档位时，每处规则都写"硬性/最高优先级"，
  结果是处处都硬、等于处处不硬。分档之后：A 档是交付底线，B 档可偏离但要写明，
  C 档看场景，诊断值只汇报。改规则时先问"它属于哪一档"，再决定写进哪一栏。
- **先判断论证，再定问题，最后才排版**。大多数 AI 生成 PPT 的失败不是排版丑，
  而是"这篇论文到底证明了什么"没想清，于是把论文里的图全塞上去。
  这一版把 `claims.md` 放在分页之前，就是为了让排版没有机会决定科学。
- **图数是诊断指标，不是门槛**。硬性"每页 2–4 张"会把不同证据硬拼、把单张决定性证据拆散；
  真正该硬的是"证据是否必要"，不是"张数是否够"。
- **图内文字大小默认不作决策依据，但"关键证据不可读"例外**。前者防止"为放大字而砍证据"；
  后者防止另一种失败：剂量梯度、组别、统计标记看不清，听众无法核验结论。
- **字号只允许落在阶梯上**。自由字号会导致"逐条微调直到塞下"，
  最后同一页出现 5 种字号、组标题比正文还小——这正是加入 type scale 门禁的原因。
- **内容极简**。每页正文 bullets ≤ 30 词（页标题不计入）、图尽可能大，让图说话，人来讲。
- **图占比是指标，不是门槛**。图要尽可能大且易读，但"本页叙述充实、证据链完整"优先级更高；
  排不满 50% 就接受并注明——为凑数字删必需证据，代价远大于版面数字。
- **文案不用装饰性符号**。人类做 PPT 时几乎不敲 `·`，一出现就暴露是机器生成——
  所以这条被做成了脚本门禁，而不是只写在文档里。
